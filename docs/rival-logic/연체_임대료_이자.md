# 연체 임대료 이자
- 그쪽 주소: https://부동산계산기.com/연체이자  · 계산 위치: 서버 (overdue 계산 API)  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /연체이자계산기  · 판정: 불일치

## 1. 입력 항목
- 월 차임(rent, 만원), 연체이율(rate, 기본 5%), 시작일·종료일(YYYYMMDD), 선택: 납부내역(pay[n] 날짜·금액), 이자부터 상환(interestFirst), 월세 변동. [측정: s01~s13 요청 본문]
- 우리: 연체 금액 1건, 연체 시작일, 기준일, 이율 버튼(민사 5/상사 6/소송 후 12/약정). [측정: specs/notes/연체이자.md, ours s01 화면]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식 [추측].
- 한 회분 연체: 이자 ≈ 월 차임 × 연이율 × (종료일 − 시작일 일수) ÷ 365, 원 단위 반올림. 계산 예: s01 3,000,000×5%×30÷365 = 12,328.77 → 응답 12,329. s05 1일 410.96 → 응답 411. [측정: s01, s05 응답 / 식은 계산으로 맞춰 본 것]
- 여러 달: 매달 같은 날짜에 월 차임이 새로 쌓이고, 날짜별 누적 이자표를 낸다(s10에서 2026-02-01 누적 4,247 = 1,000,000×5%×31÷365 반올림). [측정: s10, s13 / 식은 추측]
- 납부내역을 넣으면 납부일에 연체 원금이 줄어든다(s11: 5/10에 100만 납부 → 9,452). 이자부터 상환을 켜면 납부액이 이자를 먼저 줄인다(s12: 5,764). [측정: s11, s12]

## 3. 상수·구간표
- 일할 금리 = 연이율 ÷ 365(응답 비고 "약 0.0137%" = 5% 기준). [측정: s01]
- 윤년 해(2024)에도 365로 나눈 값으로 보인다: 2일 822 = 3,000,000×5%×2÷365. [측정: s06 / 계산으로 확인]
- 이율 선택지(5/6/12%)는 그쪽 화면 값으로 s02, s03에서 12%, 6%가 정상 처리됨. [측정]

## 6. 판정과 불일치 예시
- 판정: 불일치. [측정]
- 불일치 예시: 월 차임 5,000만원·연 5%·5/1~5/30 → 그쪽 198,630원(30일 기준) vs 우리 191,780원(28일 기준). [측정: s09]
- 원인 두 가지. 첫째, 우리 표본은 시작일을 하루 늦춰 입력해 일수가 1일 짧다(s01, s02, s03, s09에서 29일·28일). 같은 날짜를 넣으면 우리 식(src/calcs/CalcLateInterest.jsx:19-20)은 3,000,000×5%×30÷365 = 12,328.77을 내림해 12,328원이 되고 그쪽은 12,329원이므로, 날짜를 맞춰도 내림/반올림 차이 1원이 남는다. [측정: 식 비교 / 12,328은 계산한 값이며 실행 결과는 아님] 둘째, 우리는 끝전을 내림(Math.floor), 그쪽은 반올림으로 보인다(s05 410 vs 411). [측정: s05]
- 우리는 월 차임이 매달 쌓이는 구조·납부내역·이자부터 상환이 없어 s10~s13은 구조적으로 비교하지 못한다. 우리 코드는 읽기만 했다.

## 7. 못 찾음·미확인
- s10~s13: 다회차·납부내역 표본이라 우리에 대응 입력이 없어 비교 제외. [측정: specs/notes/연체이자.md]
- 그쪽 "납부 시작일"이 첫 지급일인지 연체 시작일인지는 응답만으로 확정하지 못했다(종료일−시작일 일수를 쓰는 것으로 보임).
- 같은 날짜 입력으로 우리 계산기를 다시 돌린 결과는 이번에 없다(표본 재실행 금지).
