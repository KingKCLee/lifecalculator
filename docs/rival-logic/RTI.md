# RTI
- 그쪽 주소: https://부동산계산기.com/rti  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /RTI계산기 (부분 대응: 대출금액 x 금리로 이자를 만드는 방식만)  · 판정: 불일치

## 1. 입력 항목
- 임대물건: 주택(housing) / 비주택(nonHousing). 연간 임대소득: 만원. [측정: s01, s04 요청]
- 간편 모드: 연간 이자비용(만원)을 직접 입력. 상세 모드(detailYn=Y): 보증금 간주소득, 신규 대출금액, 기존대출 연이자(만원), 금리(%), 금리유형 변동/고정, 스트레스 가산금리(기본 1%p), 상환방식(만기일시/원금균등, 기간 개월). [측정: s08~s12 요청]
- 우리 쪽 입력: 건물 유형 토글(주거용 1.25배 / 비주거용 1.5배), 연간 임대소득(만원), 대출금액(만원), 연 금리(%). 이자비용 직접 입력, 보증금 간주소득, 기존 대출, 금리유형, 상환방식은 없음. [측정: 우리 s01 화면 텍스트]

## 2. 계산식 정리
서버 계산. 응답 행에서 읽히는 식 [추측: 입출력으로 추정한 식].
- 간편 모드: RTI = 연간 임대소득 / 연간 이자비용, 소수 둘째 자리 표시 [측정: s01 1,250만/1,000만 = 1.25].
- 판정은 반올림 전 값으로 하는 것으로 보인다: 임대소득 1,249만원이면 RTI 표시는 1.25 인데 "기준 미달" [측정: s02]. 1,251만원은 "기준 이상" [측정: s03].
- 기준: 주택 1.25, 비주택 1.5 [측정: s01, s04 비교 문구].
- 상세 모드: 신규대출 연이자 = 대출금 x 적용금리 (만기일시, s08: 5억 x 5% = 25,000,000), 적용금리 = 변동이면 약정금리 + 스트레스 가산 (s09: 5% + 1%p = 6%), 고정이면 약정금리 [측정: s08, s09].
- 연간 이자비용 합계 = 신규대출 이자 + 기존대출 연이자 (s10: 25,000,000 + 5,000,000) [측정: s10].
- 원금균등(s11)은 초년도 월별 잔액 기준 이자 23,854,167원 [측정: s11].
- 인정 임대소득 = 연 임대료 + 보증금 간주소득 (s12: 2,400만 + 600만 = 3,000만) [측정: s12].
- 임대소득 0 이면 RTI 칸이 비고 "기준 미달"로 표시, 이자비용 0 이면 거부 [측정: s13, s07].

## 3. 상수·구간표
- 참고기준 주택 1.25배, 비주택 1.5배 [측정: s01, s04]. 스트레스 가산 기본 1%p [측정: s09 요청 stressRate=1].
- 임대소득 구간별 세율표 같은 것은 없음.

## 6. 판정과 불일치 예시
- 9표본 중 8표본이 같고 1표본(s13)이 달라 판정은 불일치. [측정: 위 표]
- 불일치 예시: 임대소득 0·이자 1,000만원 → 그쪽 RTI 칸 공란 + "기준 미달" 결과 vs 우리 "연간임대수입을 입력해주세요" 안내와 0.00배. 우리는 0 을 필수 입력 미충족으로 보고 그쪽은 0 을 정상 입력으로 계산한다 [측정: s13 양쪽]. 우리 코드는 App.jsx 의 CalcRti(2993행 부근) [측정: notes/rti.md].
- 우리 화면에는 그쪽에 없는 "기준 충족 최대대출" 값이 추가로 나온다 (예: s02 199,840,000원) [측정: 우리 s02]. 비교 대상 아님.

## 7. 못 찾음·미확인
- s07 은 그쪽이 계산을 거부(success=false)해 비교에서 뺐다(우리는 이자 직접 입력이 없어 입력 불가).
- s09, s10, s11 은 우리에 금리유형·기존 대출·상환방식 입력이 없어 비교 불가. [측정: notes/rti.md]
- 그쪽이 RTI 판정을 반올림 전 값으로 하는지의 정확한 방식은 모름(표본 s02, s05 로 그렇게 보임 [추측]).
