# 대출대환 이자
- 그쪽 주소: https://부동산계산기.com/대출대환  · 계산 위치: 서버  · 측정일: 2026-10-15 [측정:라이브 부동산계산기.com]
- 우리 대응: /대환대출비교 (일부 대응: 원리금균등·같은 금액·년 단위만)  · 판정: 불일치 (성공 표본 범위에서만, R10)

## 1. 입력 항목
- 기존 대출과 변경(대환) 대출 각각: 상환방식(만기일시/원리금균등/원금균등/체증식), 금액(만원), 기간(개월), 금리(%). 대환 금액이 기존보다 작으면 일부 대환으로 계산한다. 대환 쪽에 추가 상환 이벤트(회차·금액)를 넣을 수 있다. [측정: s01, s03 요청, notes/대출대환.md]
- 우리 입력: 남은 원금(만원), 기존 금리, 기존 잔여 기간(년), 신규 금리, 신규 대출 기간(년), 중도상환수수료율, 기존 대출 경과연수. 상환방식 선택 없이 모두 원리금균등, 신규 금액은 기존과 같다. [측정: ours-capture 화면 텍스트, calcs/CalcRefinance.jsx:15-33]

## 2. 계산식 정리
서버 계산이다. 응답 표에서 읽히는 내용 [측정: s01 응답], 식은 입출력 추정 [추측].
- 그쪽은 기존/변경 대출 각각의 상환표(회차별 원금·이자·납부액·잔액)를 내고, 총이자 = 상환표 이자 합계, 연이자 = 초년도 이자 합계로 보인다. [측정: s01 비고 "초년도 기준"]
- 총이자 차이 = 기존 총이자 - 변경 총이자, 연이자 차이도 같은 식. 음수이면 대환이 불리. [측정: s05, s08]
- 원리금균등 월 납부액 = 원금 x r x (1+r)^n / ((1+r)^n - 1), r = 연금리/12. s01 기존 1,610,465원, 변경 1,347,134원이 이 식과 같다. [측정: s01 상환표 1회 납부액 / 추정식]
- 우리 식: 월 원리금(반올림) 차이 = 월 절감액, 총 절감 = 월 절감액 x 신규 기간(개월) - (중도상환수수료 + 고정 기타비용 500,000원). [측정: CalcRefinance.jsx:30-33]

## 3. 상수·구간표
- 그쪽: 연 12개월, 이자 계산에 소수 금리 사용 (5%, 3.5%). 상수 구간표 없음.
- 우리: 기타 비용(인지세 등) 500,000원 고정, 중도상환수수료 = 원금 x 수수료율 x (1 - 경과연수/3, 0 이상). [측정: CalcRefinance.jsx:27-30]

## 6. 판정과 불일치 예시
- 5표본 중 1표본(s07)만 총액까지 같고 5표본 모두 월 원리금은 원 단위로 같다. 판정은 불일치이며 이 결과는 원리금균등·같은 금액·추가상환 없음 범위에 한정된다 (R10). [측정: 위 표]
- 원인 1 (s01, s08, s12): 그쪽은 상환표의 이자 합계로 차이를 내고, 우리는 반올림한 월 절감액에 개월 수를 곱한다. 반올림 누적으로 70원~342원 차이가 난다. [측정: s01 94,799,090 vs 94,799,160 / 코드 근거: CalcRefinance.jsx:20-21, 30-33]
- 원인 2 (s06): 두 대출의 기간이 다르면 우리는 월 절감액(음수) x 신규 기간 240개월로 계산한다. 그쪽은 기존 360개월 전체 이자와 변경 240개월 이자를 비교해 162,196,356원 절감으로 낸다. 부호까지 반대다. [측정: s06 / 코드 근거: CalcRefinance.jsx:33]
- 원인 3 (전 표본, 기준 차이): 우리 화면은 기타 비용 500,000원을 항상 뺀다. 그쪽은 비용 입력이 없다. 화면 총액으로는 s07 에서 그쪽 0 vs 우리 -500,000원이 된다. [측정: s07 양쪽 값 / CalcRefinance.jsx:28]
- 불일치 예시: 3억원, 기존 5%·360개월 → 신규 3.5%·240개월 원리금균등 → 그쪽 총이자 차이 162,196,356원 절감 vs 우리 대환 총 절감액 -31,559,360원 ("중도상환수수료 > 이자 절감. 대환 비권장" 표시). [측정: s06]

## 7. 못 찾음·미확인
- s10 (실행 실패): 실패 사유 "locator.fill: Timeout 32000ms exceeded." (3회+ 재시도 후 기록). 대환 12회차 5,000만원 추가상환 표본이라 추가상환 반영식은 못 찾음. [측정: s10.json, progress.json failReason]
- s02, s03, s04, s05, s09, s11 은 그쪽 결과가 있으나 우리에 만기일시·원금균등·체증식·일부 대환·1개월 입력 경로가 없거나 우리 표본을 만들지 않아 비교하지 않았다 (실행 실패 아님). [측정: notes/대출대환.md, specs/ours/대출대환.json 표본 목록]
- 그쪽이 기존 대출을 새로 시작하는 대출로 보는지 일부 상환된 잔액으로 보는지는 모름 (경과 개월 입력 없음).
- 일치 판정(s07)은 성공 표본 5건 범위에서만이다.
