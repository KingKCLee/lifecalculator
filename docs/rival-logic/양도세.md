# 양도세
- 그쪽 주소: https://부동산계산기.com/양도세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /양도소득세계산기 (App.jsx CalcTrans)  · 판정: 불일치

## 1. 입력 항목
- 양도물건(realEstateType): 주택 / 분양권(right) / 입주권 / 비사업토지(land) / 기타 [측정: s01, s11, s12 요청값]
- 주택수(own=one/two/more), 아파트 여부(aptYn), 조정대상지역(conArea), 공동명의(jointOwnership)와 지분(jointRate) [측정: s06, s08, s15]
- 취득가액(buyAmt)·양도가액(sellAmt)·필요경비(cost) 만원 단위, 취득일(buyDate)·양도일(sellDate) YYYYMMDD [측정: s01 요청값]
- 거주기간(liveYear), 임대기간(rentYear), 1주택일자 등 고급 칸이 더 있으나 표본에서 비워 두었다 [측정: 요청 파라미터]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 양도차익 = 양도가액 - 취득가액 - 필요경비 [측정: s03 15억-5억=10억]
- 1세대1주택 12억 이하 전액 비과세 (s01, s02 세액 0), 12억 초과는 초과분 비율로 안분 (s03: 과세대상 양도차익 2억 = 10억 x (15-12)/15) [측정]
- 장기보유특별공제 = 과세대상 양도차익 x 공제율 (s03: 2억 -> 44,000,000 = 22%, 보유 11년 3개월 x 연 2%) [측정]
- 과세표준 = 양도차익 - 장특공제 - 기본공제 250만 (s07: 5억-8천만-250만=417,500,000) [측정]
- 세액 = 과세표준 x 세율 - 누진공제. s07: 417,500,000 x 40% - 25,940,000 = 141,060,000 [측정: 산술이 응답과 일치]. s03: 153,500,000 x 38% - 19,940,000 = 38,390,000 [측정]
- 지방소득세 = 양도세 x 10%, 총 납부금액 = 양도세 + 지방소득세 [측정: s03]
- 단기: 보유 1년 미만 70%, 1~2년 60% 단일세율 (s04, s05), 장특공제 없음 [측정]
- 조정대상 다주택은 기본세율에 +20%p(2주택, 60%) / +30%p(3주택 이상, 70%)를 더하고 장특공제를 빼는 구조 (s06, s08) [측정]
- 비사업용 토지는 기본세율 +10%p (s11: 48%) [측정]

## 3. 상수·구간표
- 기본세율 관찰 구간: 6%(과표 550만, s14), 38%(1.535억, 2.075억, s03/s15 — 1.5억 초과~3억 이하 구간), 40%(4.175억, 3억 초과~5억 이하), 누진공제 25,940,000(40%), 19,940,000(38%) [측정]
- 장특공제: 보유 3년 0개월 6% (3천만/5억, s09), 8년 7개월 16% (8천만/5억, s07), 11년 3개월 22% (s03), 11년 6개월 22% (s11 6,600만/3억), 10년 7개월 20% (s14 200만/1천만) [측정]
- 보유 계산은 취득일 당일 포함으로 보인다: 취득 20230702, 양도 20260701을 "3년 0개월"로 보고 장특 6%를 적용 (s10) [측정]

## 6. 판정과 불일치 예시
- 판정: 불일치 (10/15). [측정: ours-capture/runs/양도세/s03, s06, s08, s10, s11]
- 불일치 예시: 조정대상지역 3주택 이상, 취득 5억·양도 10억, 보유 8년 7개월 -> 그쪽 총 납부금액 354,541,000원(세율 70%) vs 우리 155,166,000원(세율 40%).
- 원인 1(중과): 우리는 조정대상지역 체크만으로는 중과가 붙지 않고, 별도 칩 "조정 중과 2주택/3주택"을 켜야 +20%p/+30%p가 붙는다 (src/App.jsx:2334-2335, 칩 정의 2441/2443). 표본은 조정대상지역만 켰고 그쪽은 같은 입력에서 60%/70%를 낸다 [측정: s06, s08; 칩을 켜지 않은 것은 specs/notes/양도세.md의 입력 매핑에 근거].
- 원인 2(장특 공제율): s03에서 우리는 1주택 보유 40%(장특 80,000,000)를 쓰고 그쪽은 22%(44,000,000)를 쓴다. 그쪽은 거주기간 칸을 비웠을 때 보유분만 계산한 것으로 보인다 [측정: s03 양쪽 장특 금액 / 거주기간 해석은 추측].
- 원인 3(보유기간 일수): 취득 20230702, 양도 20260701 (s10)에서 우리는 3년 미만으로 보아 장특 0원(총 190,366,000), 그쪽은 3년 0개월로 보아 장특 30,000,000 (총 177,166,000) [측정: s10].
- 원인 4(비사업용 토지): 우리는 +10%p 추가과세가 별도 체크(nonBizLand, App.jsx:2338-2340)라 s11에서 38%로 나오고 그쪽은 48% [측정: s11].
- 우리와 같게 나온 것: 1주택 비과세와 단기 60%/70% 단일세율(s04, s05), 2주택 비조정 장특·기본세율(s07, s09, s14), 공동명의 지분 안분(s15), 분양권(s12) [측정].

## 7. 못 찾음·미확인
- 거주기간·임대기간·1주택일자·입주권 가치·차익조정 등 고급 입력은 표본에서 비웠으므로 효과는 확인하지 못했다.
- 그쪽 장특 공제율표(1주택 보유 4%/년+거주 4%/년 등) 전체는 표본 부족으로 확정 못 함.
- 2026-05-10 이후 다주택 중과 유예 종료 여부를 그쪽이 어떻게 처리하는지 응답 basis에서는 못 찾음 (s06/s08은 양도일 2026-08-10이고 중과가 적용됨).
