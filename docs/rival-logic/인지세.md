## 1. 입력 항목

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 인지세 = 거래금액 구간별 정액. 1천만 이하 0, 이후 금액이 커질수록 2만 / 4만 / 7만 / 15만 / 35만으로 올라간다 [측정: s01~s14]
- 경계값은 "초과"가 윗구간 (1천만 정확 0, 1천만 1만원 초과 시 20,000 등) [측정: s02/s03, s04/s05, s06/s07, s08/s09, s10/s11]

## 6. 판정과 불일치 예시
- 판정: 불일치 (6/14). [측정: ours-capture/runs/인지세/s03~s08, s13, s14]
- 불일치 예시: 거래금액 5,001만원 -> 그쪽 인지세 70,000원 vs 우리 0원.
- 원인(우리 코드 줄): 우리는 1억 이하를 전부 비과세로 두고(src/App.jsx:3298 baseStamp 계산, 1억 초과부터 150,000) 1천만~1억 사이 2만/4만/7만 구간이 없다 [측정: 코드 읽기, s03~s08]. 또 30억 초과를 500,000원으로 두는 구간이 있어(같은 줄) 30억 1만원·100억에서 그쪽 350,000과 달라진다 [측정: s13, s14].
- 우리 화면은 전자계약 체크박스(70% 할인)가 따로 있다. 이번 비교는 체크하지 않은 값이다 [측정: specs/notes/인지세.md].

## 6-1. 기준차이 판단 근거 (법령 원문)
- 인지세법(법률 시행 2025-10-01, law.go.kr 국가법령정보센터 DRF 조회) 제6조(비과세문서) 제5호 원문: "주택의 소유권 이전에 관한 증서로서 기재금액이 1억원 이하인 것" — 이 문서에는 인지세를 납부하지 아니한다 [측정: 법제처 DRF API 응답, 법령ID 001568].
- 따라서 주택 1억원 이하 0원(우리)은 법령과 같고, 1천만원 초과~1억원 이하 세액(그쪽)은 주택 외 부동산(토지·상가 등)에만 맞다. 이 구간을 '오류'가 아닌 '기준차이(물건 종류 입력 해석)'로 분류했다 [측정: 위 원문, s03~s08].
- 우리 화면(src/calcs/CalcStamp.jsx)에 주택/주택 외 물건 종류를 고르는 칸이 있는지 확인한 결과 해당 칸을 못 찾음(코드에서 '주택·토지·종류·select' 검색 0건) [측정:로컬 CalcStamp.jsx grep]. 따라서 주택 외 물건의 1천만원 초과 구간(2만·4만·7만원)은 우리 화면에서 고를 수 없다. → 대표님 결정 목록에 "주택 외 물건 인지세 구간 추가 여부"로 올림.
