## 2. 계산식 정리
서버 계산이며 응답 비고와 표본 값으로 정리.
- t년차 NOI = 1년차 NOI × (1+증가율)^(t−1) — s02: 50,000,000 → 51,000,000 → 52,020,000 [측정]
- t년차 현재가치 = t년차 NOI ÷ (1+할인율)^t (응답에 현가계수 표시, 소수 6자리) — s01 [측정]
- 말기 환원가치 = 다음해(보유기간+1년차) NOI ÷ 말기 환원율. s02 에서 54,121,608×1.02÷0.05 = 1,104,080,803 [측정]
- 처분비용 = 말기 환원가치 × 처분비용률, 순 말기가치 = 말기 환원가치 − 처분비용 — s03 [측정]
- 순 말기가치 현재가치 = 순 말기가치 × 보유기간 말 현가계수 — s01 [측정]
- DCF 수익가격 = NOI 현재가치 합계 + 순 말기가치 현재가치 — s01 [측정]
- 입력 검증: 보유기간 1~30년, 할인율>0, 말기 환원율>0, 1년차 NOI 입력 필수 — s07~s10, s14 [측정]

우리 식(CalcAppraisalMethods.jsx:81-83): NOI 현재가치 합 = Σ NOI×(1+g)^(i−1)÷(1+d)^i, 복귀가액 = NOI×(1+g)^Y ÷ 기말환원율 × (1−매각비용률), 복귀가액 현재가치 = 복귀가액÷(1+d)^Y [측정: 코드 읽기]. 보유기간은 반올림 후 1~30으로 묶고 빈칸·0은 10으로 대체(코드 :80). 식은 그쪽과 같다.

## 6. 판정과 불일치 예시
- 판정: 불일치 [측정]
- 원인: 우리 입력칸 % 항목이 마이너스 부호를 받지 않는다(src/calcs/_shared.jsx:64 가 숫자와 점만 허용). 성장률 −3 을 넣으면 입력이 무시되어 0% 로 계산됨 → 값이 s01 과 같은 957,876,362원. 우리 식에 −3% 를 직접 넣으면 840,753,786원으로 그쪽과 같음 [측정: 계산은 작성자가 우리 식으로 재현].
