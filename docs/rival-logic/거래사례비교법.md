## 2. 계산식 정리
서버 계산이므로 응답 비고에 적힌 식 정리.
- 사례 거래단가 = 거래금액 ÷ 사례면적 — 응답 비고, s01 [측정]
- 보정단가 = 거래단가 × (시점% ÷100) × (지역% ÷100) × (개별% ÷100) × (기타% ÷100). 4개 요인을 곱함. s07 에서 1.025×0.98×1.05×0.97 이 적용됨(화면 비고는 시점을 1.03으로 반올림 표시하지만 계산은 9,743,650원으로 소수 그대로 곱한 값과 일치) [측정]
- 사례 시산가액 = 보정단가 × 대상면적 — s01, s02 [측정]
- 거래사례비교가액 = 사례 시산가액의 가중평균(가중치 합으로 나눔). 사례 1건이면 그 시산가액 그대로. s11 에서 (800M+840M)÷2=820M, s12 에서 (800M×3+840M×1)÷4=810M, s13 에서 814,496,000 [측정]
- 입력 검증: 대상 면적 0, 사례 면적 0, 거래금액 0, 가중치 0 이면 계산을 거부하고 안내문 반환 — s08, s09, s10, s14 [측정]

우리 식(CalcAppraisalMethods.jsx:26-28): 사례 ㎡당 단가 = 거래가격÷사례면적, 보정 배수 k = 사정보정 × (1+시점수정%÷100) × 지역 × 개별, 비준가액 = 단가 × k × 대상면적 [측정: 코드 읽기]. 요인을 곱하는 구조는 그쪽과 같다.
