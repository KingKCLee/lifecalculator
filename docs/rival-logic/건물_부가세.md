## 2. 계산식 정리
서버 계산이므로 아래는 응답에 적힌 비고와 숫자로 정리한 식이다. 식의 원문 코드는 못 봄.
- 토지 시가 = 토지 면적 × ㎡당 공시지가 — 응답 비고에 같은 설명이 있음, 표본 s01 [측정]
- 건물분 가액 = 취득가액 × 건물 시가 ÷ (건물 시가 + 토지 시가) — 응답 비고, 표본 s01~s03 [측정]
- 건물 부가세 = 건물분 가액 × 10% — 응답 비고 [측정]
- 즉 취득가액을 부가세가 빠진 공급가액으로 보고 곧바로 10%를 곱함. s01 에서 5억 × 10% = 5천만원 [측정]
- 건물분 가액은 s13 에서 33,332원(소수 버림 또는 반올림 어느 쪽인지는 이 표본만으로는 구분 못 함), 부가세 3,333원 — 반올림 방식은 [추측]
- 입력값 검증: 토지 면적 0 또는 취득가액 0 이면 계산하지 않고 안내문을 돌려줌 — 표본 s05, s06 [측정]

우리 식 (CalcBldVat.jsx:42-47) [측정]
- 토지가 = 총매매가 × 토지비율, 건물 총액 = 총매매가 − 토지가
- 과세 대상(주택 85㎡ 이하·토지 제외)이면 건물 공급가액 = 건물 총액 ÷ 1.1, 부가세 = 건물 총액 − 공급가액
- 즉 총매매가를 부가세 포함 금액으로 봄. 같은 비율이라면 그쪽 값은 우리 값의 1.1배.

## 6. 판정과 불일치 예시
- 판정: 불일치 [측정]
- 원인 1 — 취득가액을 부가세 포함으로 보느냐: 우리는 CalcBldVat.jsx:46 에서 건물 총액을 1.1로 나누고, 그쪽은 취득가액을 곧바로 공급가액으로 보고 10%를 곱함. 10개 표본(s01~s03, s07~s13)에서 그쪽 값 = 우리 값 × 1.1 에 가깝다 [측정: s01 45,454,545×1.1=49,999,999.5].
- 원인 2 — 입력 구조: 그쪽은 건물 시가·공시지가·면적을 받아 안분하고, 우리는 토지비율(%)을 사람이 직접 넣는다(CalcBldVat.jsx:119). 비율을 소수 4자리로 넣은 표본에서 1.1배를 보정해도 잔차가 남음(s07 우리×1.1=1,666,665 vs 1,666,667, s13 우리×1.1=3,300 vs 3,333) [측정: 계산은 작성자].
- 불일치 예시: 취득 10억·건물 3억·토지 100만/㎡×300㎡(토지비율 50%) → 그쪽 건물 부가세 50,000,000원 vs 우리 45,454,545원 (s01).
