# 착한임대인
- 그쪽 주소: https://부동산계산기.com/착한임대인  · 계산 위치: 서버 (/api/goodRent.php)  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /착한임대인공제  · 판정: 불일치

## 1. 입력 항목
- 종합소득(income, 만원), 공제 금액(deduct, 만원), 기존 임대료(rent), 감액 임대료(discountRent, 월 기준으로 확인됨), 세액공제율(taxDeductRate, % 기본 70), 기간(period, 개월, 기본 6). [측정: g01~g14 요청 본문, g01 응답 "(3000000 - 1500000) × 6"]
- 우리: 기존 월 임대료, 인하 후 월 임대료, 인하 기간, 소득 구간 토글(1억 이하 70% / 초과 50%). 종합소득·공제 금액·공제율 직접 입력은 없다. [측정: specs/notes/착한임대인.md, ours g01 화면]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식 [추측]. 응답이 단계를 보여 준다.
- 임대료 감소액 = (기존 − 감액) × 기간. 음수도 그대로 둔다. [측정: g01, g05 응답 비고]
- 세액공제액 = 임대료 감소액 × 공제율. [측정: g01 "9000000 × 70%", g06 "12000000 × 50%"]
- 그 밖에 할인 전후 종합소득세(누진세율 적용)를 각각 계산해 "세금 혜택 = (할인 전 세액 − 할인 후 세액) + 세액공제액"을 낸다. [측정: g01 응답]
- 공제율은 사용자가 입력한 값을 그대로 쓰고 소득 1억 경계에서 자동 변경하지 않는다. [측정: g07, g08 둘 다 70%로 8,400,000]
- 세액공제액은 산출세액 한도 안으로 잘리지 않는다(산출세액 0인 g13, g14에서도 6,300,000). [측정: g13, g14]
- 기간 12개월 초과 입력(g11 13개월)도 거절하지 않고 계산한다. [측정: g11]

## 3. 상수·구간표
- 종합소득세율: 1,200만 이하 6%, 4,600만 이하 15%, 8,800만 이하 24%, 1.5억 이하 35% 등이 응답 비고에 나온다. 1.5억 초과 구간은 표본이 없다. [측정: g01~g08]
- 세액공제율 기본 70, 기간 기본 6개월. [측정: g02]
- 페이지 안내문은 코로나-19 시기의 일시적 제도라고 쓰여 있다. 지금도 유효한지는 못 찾음. [측정: specs/notes/착한임대인.md html 755행 인용]

## 6. 판정과 불일치 예시
- 판정: 불일치(1건). [측정] 이 결론은 "소득 입력 없이 인하액×공제율만" 비교한 범위 안에서 성립한다.
- 불일치 예시: 기존 월세 300만→400만(올림), 6개월, 70% → 그쪽 세액공제액 -4,200,000원 vs 우리 0원. 우리는 월 인하액을 0 아래로 내리지 않는다(src/calcs/CalcGoodLandlord.jsx:15). [측정: g05 / 원인은 코드 읽기]
- 우리 코드는 읽기만 했다.
