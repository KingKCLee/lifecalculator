# 재산세
- 그쪽 주소: https://부동산계산기.com/재산세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /재산세계산기 (App.jsx CalcProp)  · 판정: 불일치

## 1. 입력 항목
- 주택 전제 폼: 공시가격(만원, property[0][amount]), 1세대1주택(oneHouse=Y), 도시지역(cityArea=Y), 공동명의 지분(share), 세부담상한(burdenLimit=Y)과 전년도 재산세·도시지역분(만원), 기준연도(baseYear=2026) [측정: s01, s08, s14, s15 요청값]
- 공정시장가액비율 propTaxFairRate=0 을 항상 보냄 (자동 선택으로 보임) [추측]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 과세표준 = 공시가격 x 공정시장가액비율 (일반 주택 60%, s01: 1억 -> 6천만) [측정]
- 재산세 본세 = 과세표준에 누진세율 적용 (6천만 이하 0.1%, 1.5억 이하 0.15%, 3억 이하 0.25%, 초과 0.4%의 누진 [추측: s01 60,000, s03 195,000, s05 570,000, s07 1,770,000 수치와 일치하는 식])
- 도시지역분 = 과세표준 x 0.14% (s01: 60,000,000 -> 84,000) [측정 수치 일치]
- 지방교육세 = 재산세 본세 x 20% (s01: 60,000 -> 12,000) [측정 수치 일치]
- 총 납부액 = 재산세 + 도시지역분 + 지방교육세 [측정: s01 합 156,000]. 지역자원시설세는 합계에 들어가지 않는다.
- 1세대1주택 특례: 공정가액 3억 이하 43%, 6억 이하 44%, 9억 이하 45% (s08 43%, s09 44%, s11 45%) 와 특례 세율 적용(s08 본세 99,000) [측정]
- 세부담상한: 본세와 도시지역분을 각각 전년도 x 110%로 제한하고 지방교육세는 제한 후 본세 기준 [측정: s14 220,000, 55,000, 44,000]

## 3. 상수·구간표
- 일반 주택 본세 관찰값: 과표 6천만 60,000 / 1.5억 195,000 / 3억 570,000 / 6억 1,770,000 [측정: s01, s03, s05, s07]
- 1세대1주택 특례 본세: 과표 1.29억 99,000, 2.64억 348,000, 4.05억 787,500 [측정: s08, s10, s12]
- 공정시장가액 9억 초과 1세대1주택: 과표가 405,004,500(45%)인데 본세 990,018로 일반세율로 계산된 값이다 (s13) [측정]. 9억 이하(s12)는 45% 과표에 특례세율 787,500.

## 6. 판정과 불일치 예시
- 판정: 불일치 (0/14). [측정: ours-capture/runs/재산세/s01~s14]
- 불일치 예시: 일반 주택 공시가격 5억 -> 그쪽 총 납부액 1,104,000원 vs 우리 1,120,900원.
- 원인 1(일반 주택, s01~s07): 우리는 총액에 지역자원시설세를 더한다(src/App.jsx:2607 이하 CalcProp 의 rt 계산, 합계 rawTotal = 본세+도시지역분+교육세+rt). s01 차이 2,400원, s03 7,100원, s05 16,900원이 모두 그 지역자원시설세 값과 맞는다 [측정: 총액 차이 / 추측: rt 값과의 대응은 코드 읽기와 수치 일치로 판단]. 본세·도시지역분·교육세 항은 그쪽 수치와 같은 식으로 보인다.
- 원인 2(1세대1주택, s08~s13): 우리는 특례 시에도 일반 누진세율 표(0.1~0.4%)로 본세를 낸다 (App.jsx CalcProp pTx 호출). 그쪽 s08 본세 99,000은 특례세율(0.05% 등) 값으로 보인다 [추측: 129,000,000 기준 30,000+(69,000,000 x 0.1%)=99,000 과 일치]. 또 우리는 9억 초과를 60%로 되돌리는데(fr=0.60) 그쪽 s13은 45% 과표를 유지한다 [측정: s13 과세표준 405,004,500].
- 원인 3(세부담상한, s14): 우리는 전년도 합계 1칸에 110%를 곱해 전체 총액을 깎는다 (275,000). 그쪽은 본세·도시지역분 각각 상한 후 교육세를 붙여 319,000 [측정: s14 항목 값].
- 우리에 없는 것: 공동명의(s15), 조정대상지역, 기준연도 [측정: specs/notes/재산세.md].

## 7. 못 찾음·미확인
- s15(공동명의)는 우리에 해당 입력이 없어 비교 제외.
- 토지·건축물 재산세는 그쪽 폼이 주택 전제라 표본이 없다.
- 그쪽 공정시장가액비율 0(자동) 선택 규칙의 전체 구간과 도시지역분 0.14% 외 경우는 못 찾음.
- 9억 초과 1세대1주택에서 그쪽이 일반세율을 쓴다는 해석(s13)은 한 표본뿐이라 확정 못 함.
