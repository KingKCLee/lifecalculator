# 대출가능액
- 그쪽 주소: https://부동산계산기.com/대출가능액  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /LTV계산기 (같은 입력 축 일부: 규제지역·주택 수·생애최초·서민실수요자·기존 대출)  · 판정: 불일치

## 1. 입력 항목
- 시세(담보가치)·선순위채권·임차보증금: 만원. 지역(서울/수도권/광역시/기타), 부동산유형(아파트/기타 주택/상가), 규제구분(비규제/조정대상/투기과열), 보유 현황(무주택 또는 1주택 처분조건 / 서민실수요 / 다주택), 생애최초 체크, 방 공제 체크, 방 수. [측정: s01~s13 요청, notes/대출가능액.md]
- 우리 쪽 입력: 주택 가격(시세), 규제지역 3종, 주택 수(1/2/3 이상), 우대 조건(생애최초/서민실수요자), 기존 담보대출 잔액. 지역·유형·방 공제·임차보증금은 없음. [측정: 우리 s01 화면 텍스트, App.jsx:2990-3010]

## 2. 계산식 정리
서버 계산 [추측: 입출력으로 추정한 식].
- 기준 LTV: 비규제 70%, 조정대상 40%, 투기과열 40%, 투기과열 서민실수요 70%, 비규제 생애최초 70% [측정: s01, s06, s04, s08, s09 비고].
- 담보가능액 = 담보가치 x 기준 LTV (9억 초과에도 같은 비율: s01 10억 x 70% = 7억) [측정: s01, s03].
- 차감 금액 = 최우선변제금액(서울 방 수 1 x 55,000,000원, 방 수를 비워도 1로 적용됨) + 선순위채권 [측정: s01, s10].
- 대출가능액 = 담보가능액 - 차감 금액 [측정: s01 7억 - 5,500만 = 6.45억].
- 투기과열 + 다주택은 0 (s07) [측정].
- 화면에 "상한 금액" 행(15억 이하 6억, 15~25억 4억, 25억 초과 2억)이 나오지만 대출가능액에 반영되지 않는다: s01 상한 6억인데 대출가능액 6.45억, s05 상한 4억인데 5.454억 [측정: s01, s05, s11, s12 응답]. s04(15억)는 상한 행이 없다 [측정: s04].
- 소액보증금은 지역별 값 (서울 55,000,000, 광역시 48,000,000원) [측정: s01, s11].
- 입력 검증: 담보가치 0 거부 [측정: s13].

## 3. 상수·구간표
- LTV 위 표. 상한 구간 15억/25억 [측정: s05, s11, s12 비고 문구]. 9억 구간 분할은 그쪽 응답에서 안 보임 (s01, s03) [측정].
- 소액보증금: 서울 5,500만원, 광역시(metro 선택) 4,800만원 [측정: s01, s11].

## 6. 판정과 불일치 예시
- 11표본 중 2표본만 일치해 판정은 불일치. 원인 4가지 [측정: 위 표 + 우리 코드 읽기].
  1. 소액보증금 차감: 그쪽만 5,500만원을 뺌 (s02 차이가 정확히 55,000,000).
  2. 규제지역별 비율: 조정대상 그쪽 40% vs 우리 50% (코드 App.jsx:2998), 서민실수요 투기과열 70% vs 60% (2996), 생애최초 비규제 70% vs 80% (2995).
  3. 9억 초과분 20% 분할: 우리만 적용 (App.jsx:3009-3010).
  4. 15억 초과 투기과열: 우리는 0 (App.jsx:3007), 그쪽은 계산함.
- 불일치 예시: 서울 비규제 무주택, 시세 9억 → 그쪽 575,000,000원 vs 우리 630,000,000원 (그쪽이 소액보증금 5,500만원 차감). 서울 투기과열 시세 15.01억 → 그쪽 545,400,000원 vs 우리 0원.
- 그쪽 자체 모순: 상한 행(6억 등)을 보여주면서 대출가능액은 상한을 넘는다 (s01, s05) [측정].
