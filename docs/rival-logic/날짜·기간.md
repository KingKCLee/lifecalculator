# 날짜·기간
- 그쪽 주소: https://부동산계산기.com/날짜  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /날짜계산기 (부분 대응: 두 날짜 간격만)  · 판정: 불일치

## 1. 입력 항목
- 모드 라디오(dcd): 기간 구하기(duration) / 미래·과거 날짜 구하기(date). [측정: s01, s10 요청]
- 시작일(startDate)·종료일(endDate): 숫자 8자리 YYYYMMDD. 종료일을 비우면 오늘로 채운다. [측정: s08 응답 "종료일자 2026-10-15 / 오늘"]
- 초일 산입 체크(firstDay=include). 날짜 모드의 가감 입력: 년·월·일(addYear/addMonth/addDay, 일은 음수 허용)과 방향(after/before). [측정: s06, s10~s13 요청]
- 우리 쪽: 모드 토글(두 날짜 간격 / D-day), 시작일·종료일 YYYYMMDD. 종료일은 화면이 뜬 뒤 오늘 날짜로 미리 채워진다. 초일 산입·날짜 가감 입력은 없다. [측정: src/calcs/CalcDateDiff.jsx:35~40, ours 표본 화면]

## 2. 계산식 정리
서버 계산이라 식은 보이지 않는다 [추측: 입출력으로 추정한 식].
- 총 일 수 = 종료일 - 시작일(초일 불산입, 같은 날 0일). 역순 입력도 절댓값 1일 [측정: s05, s07].
- 기간 "N년 M개월 D일": 달력 기준 경과. 2024-02-29 -> 2025-02-28 이 0년 11개월 30일, 2025-03-01 이 1년 0개월 0일 [측정: s03, s04].
- 총 개월 수: 달력 기준 경과 개월 (s01 12, s03 11, s08 81) [측정].
- 총 주 수 = 일수/7, 소수 둘째 자리 [측정: s01 52.29, s14 0.14].
- 존재하지 않는 날짜(2025-02-30)는 3월 2일로 넘겨 계산한다 [측정: s15 응답 시작일자 2025-03-02].
- 우리 식: 일수=두 날짜 차의 절댓값을 일 단위로 내림. 연·월은 부호를 유지한 채 연도 차, 월 차, 일 차가 음수면 월에서 1을 뺀다. 총 개월=연차x12+월차 [측정: CalcDateDiff.jsx:41~54]. 역순 입력이면 개월·연이 음수로 나온다.

## 3. 상수·구간표
- 상수 없음. 달력 규칙만 있다. 초일 불산입은 민법 제157조("기간의 초일은 산입하지 아니한다")와 같은 방향이다 [측정: law.go.kr 원문 조회, law/날짜.json]. 그쪽 날짜 가감 모드가 1월 31일+1개월=3월 3일(s10)로 넘기는 규칙은 확정하지 못했다.

## 6. 판정과 불일치 예시
- 판정: 불일치 (비교 10건 중 8건 일치, 2건 불일치). 두 불일치는 같은 원인(시작일이 종료일보다 늦는 입력)이다.
- 불일치 예시: 시작 2025-01-01, 종료 2024-12-31 -> 그쪽 총 일수 1일·총 개월수 0개월 vs 우리 총 일수 1일·총 개월수 -1개월·만 연수 -1년. 원인: 우리는 일수에만 절댓값을 쓰고(CalcDateDiff.jsx:43) 연·월 계산은 순서를 바꾸지 않아 부호가 남는다(CalcDateDiff.jsx:44~50) [측정: 코드 읽기와 s07 화면].
- 존재하지 않는 날짜 보정은 양쪽이 같다(2/30 -> 3/2) [측정: s15 양쪽 모두 2025-03-02].
- 그쪽만 있는 기능: 초일 산입(s06), 날짜 가감 모드(s10~s13). 우리에만 있는 기능: D-day 카운트, 만 연수 [측정].

## 7. 못 찾음·미확인
- s06(초일 산입)에서 그쪽 총 일 수가 같은 날인데 0일로 남는 이유(산입해도 0일)는 못 찾음.
- s10 의 1월 31일+1개월=3월 3일 규칙(말일 처리)은 그쪽 코드가 서버라 못 찾음.
- s08 은 실행일(2026-10-15)에 의존하는 값이라 같은 날 실행한 양쪽만 비교했다 [측정: ours 표본 화면 종료일 2026.10.15].
