# 법인양도세
- 그쪽 주소: https://부동산계산기.com/법인양도세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /법인양도세계산기 (src/calcs/CalcCorpTransfer.jsx)  · 판정: 불일치

## 1. 입력 항목
- 취득가액(buyAmt), 양도가액(sellAmt), 소요경비(etcAmt), 기존 과세표준(existingTaxBase, 이번 양도 제외), 이월결손금 등 공제(lossDeduction) — 모두 만원 단위 [측정: s02, s05, s11 요청값]
- 양도일자(sellDate, YYYYMMDD) — 사업연도별 세율 선택에 쓰인다 [측정: s12, s13]
- 체크 3종: 비사업용 토지(nonBusinessLand), 주택·분양권·입주권(nonBusinessHouse), 미등기(nonRegister) [측정: s08~s10 요청값]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 양도차익 = 양도가액 - 취득가액 - 소요경비 (s02: 10억-6억-500만 = 395,000,000) [측정]
- 전체 과세표준 = 기존 과세표준 - 이월결손금 + 양도차익 (s11: 395,000,000 - 100,000,000 = 295,000,000) [측정]
- 법인세 = 전체 과세표준에 누진 적용. s02: 2억 x 10% + 1.95억 x 20% = 59,000,000 [측정: 산술이 응답과 일치]
- 금번 양도건 증가분 = (기존 포함 전체 법인세 - 양도건 제외 법인세) + 추가과세 + 지방소득세 [측정: s05 40,000,000-10,000,000=30,000,000에 지방세 3,000,000 = 33,000,000]
- 지방소득세 = 법인세 합계 x 10% (s02: 59,000,000 -> 5,900,000) [측정]
- 토지 등 양도소득 추가과세 = (양도가액-취득가액) x 비사업용 토지 10% / 주택·분양권·입주권 20% (s08 40,000,000, s09 80,000,000) [측정]. 미등기 체크는 s10에서 추가과세 0으로 나왔다 [측정].

## 3. 상수·구간표
- 법인세율(2026 개시 사업연도 이후): 과표 2억 이하 10%, 200억 이하 20%, 3,000억 이하 22%, 초과 25% [측정: s03/s04, s06/s07, s14, s15(22%)]. 경계 정확값은 낮은 구간에 포함 (s03 정확히 2억 -> 10%, s06 정확히 200억 -> 20%) [측정].
- 2025년 12월 31일 양도(2025 사업연도): 4억 구간 세율 19%로 표시됨 (s12: 56,000,000) [측정]. 2026-01-01 양도는 20%(s13) [측정]. 2025 사업연도의 나머지 구간 세율은 확정 못 함.
- 추가과세율: 비사업용 토지 10%, 주택·분양권·입주권 20% [측정: s08, s09]

## 6. 판정과 불일치 예시
- 판정: 불일치 (12/13). [측정: ours-capture/runs/법인양도세/s10.json]
- 불일치 예시: 미등기 부동산, 취득 6억·양도 10억 -> 그쪽 금번 증가분 66,000,000원(추가과세 0) vs 우리 242,000,000원(추가과세 160,000,000원).
- 원인: 우리는 미등기 선택 시 (양도가액-장부가액) x 40%를 추가과세로 붙인다 (src/calcs/CalcCorpTransfer.jsx:9 EXTRA 선택지 +40%, 19행 extra 계산). 그쪽은 미등기 체크가 있어도 추가과세 항목이 0으로 나왔다 [측정: s10]. 이 값이 그쪽 사양인지 입력 방식 때문인지(체크 후 다른 칸 필요 등)는 못 가린다 [추측].
- 법인세 구간, 비사업용 토지 10%, 주택·분양권 20%, 기존 과표 합산(증가분 방식), 3,000억 초과 25%는 두 쪽이 같다 [측정: s02~s09, s13~s15].
- 우리에 없는 것: 양도일자별 세율(s12의 19%), 이월결손금 공제(s11) [측정: specs/notes/법인양도세.md]. 우리는 2026 개시 사업연도 세율 하나만 쓴다 (CalcCorpTransfer.jsx:8).

## 7. 못 찾음·미확인
- s11(이월결손금), s12(2025 사업연도)는 우리에 해당 입력이 없어 비교에서 뺐다.
- 그쪽 미등기 40% 추가과세가 어떤 조건에서 나오는지 응답에서 못 찾음 (s10 한 표본).
- 2025 사업연도의 다른 구간 세율(예: 2억 이하)은 표본이 없어 못 찾음.
- 비교는 증가분 기준이다. 기존 과표 0인 표본에서는 그쪽 "총 납부세액"과 같은 값이다 [측정].
