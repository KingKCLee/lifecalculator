# 상속지분
- 그쪽 주소: https://부동산계산기.com/상속지분  · 계산 위치: 서버 (/api/inheritShare.php)  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /법정상속분계산기  · 판정: 불일치

## 1. 입력 항목
- 상속재산(amount, 만원), 배우자 유/무(spouse), 자녀 수(children), 부모 수(parent), 형제자매(brother), 4촌 이내 방계혈족(relative). [측정: s01~s15 요청 본문]
- 우리는 상속재산·배우자 유무·자녀 수·부모 수(자녀 0일 때만 노출)만 있고 형제·4촌 입력이 없다. [측정: specs/notes/상속지분.md, src/calcs/CalcLegalInherit.jsx:10-14]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식 [추측].
- 1순위: 자녀가 있으면 분모 = 배우자 1.5(있을 때) + 자녀 수, 각자 재산÷분모(배우자는 ×1.5). [측정: s01, s04, s11, s14]
- 2순위: 자녀 0이고 부모 있으면 분모 = 배우자 1.5 + 부모 수. [측정: s02, s05, s13]
- 배우자만 있으면 전액. [측정: s03]
- 자녀가 있으면 부모 입력은 무시(s08에서 자녀 1·부모 2 → 부모 몫 없음). 자녀·부모가 모두 있어도 형제·4촌은 무시(s12, s15). [측정: s08, s12, s15]
- 상속인이 한 명도 없으면 계산하지 않고 오류 메시지를 낸다. [측정: s10]
- 반올림은 원 단위로 보인다(333,333,333 / 428,571,429). [측정: s01, s04]

## 3. 상수·구간표
- 배우자 가산: 1.5 (민법 제1009조 취지, 응답 항목 "배우자 기본 몫 1.5"). [측정: s01]
- 순위: 직계비속 > 직계존속 > 형제자매 > 4촌 이내. [측정: s06, s07, s12, s15]

## 6. 판정과 불일치 예시
- 판정: 불일치(2건). [측정]
- 불일치 예시: 상속재산 0원·배우자 있음·자녀 2명 → 그쪽 배우자 0원·자녀 각 0원 vs 우리 결과 없음(입력 요구 안내). [측정: s09] 금액 계산 문제가 아니라 0 입력 처리 방식의 차이다.
- 상속인이 전무한 경우 → 그쪽 오류 메시지 vs 우리 "단독 상속" 표시(상속인 행 없음). 원인: 우리 코드는 자녀·부모·배우자가 모두 없을 때 분기가 비어 있고(src/calcs/CalcLegalInherit.jsx:23-33) 오류를 내지 않는다. [측정: s10 / 원인은 코드 읽기]
- 지분 숫자 자체는 비교한 8건 모두 원 단위까지 같다. 우리 코드는 읽기만 했다.

## 7. 못 찾음·미확인
- s06, s07, s12, s15: 우리에 형제·4촌 입력이 없어 비교 제외. s08: 우리는 자녀가 있으면 부모 칸이 숨겨져 같은 입력을 만들 수 없어 제외. [측정: specs/notes/상속지분.md]
- 그쪽이 1순위에서 손자녀 대습상속 등을 처리하는지는 표본이 없어 못 찾음.
