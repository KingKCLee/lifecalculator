## 1. 입력 항목
- 소득 구분: 인정 소득(admit) / 신고 소득(report). 인정 소득은 국민연금(pension) / 건강보험료(healthInsurance), 신고 소득은 카드사용액(creditCard) / 기타(etc). [측정: s01, s07, s10, s11 요청]
- 월 납부액: 원 단위 (입력칸이 원 단위). 카드사용액·기타 소득: 만원 단위. 직장 소득자 체크(officeWorker), 기준연도(기본 2026). [측정: notes/추정소득.md, s01 요청 monthPaymentAmt=135000]
- 우리 쪽: 해당 계산기 없음. 이름이 비슷한 임대추정소득(estincome)은 월 임대료·보증금·보유 주택 수로 임대수입을 추정하는 다른 계산기라 대응으로 보지 않음. [측정: notes/추정소득.md]

## 2. 계산식 정리
서버 계산이라 코드는 보이지 않는다. 응답 행에서 읽히는 식 [추측: 입출력으로 추정한 식].
- 국민연금: 인정월소득 = 월 납부액 / 9.5%, 연 환산 = 인정월소득 x 12, 추정소득 = 연 환산 x 95% [측정: s01 비고, 135,000원 → 인정월소득 1,421,053 → 연 17,052,632 → 추정 16,200,000].
- 건강보험료: 인정월소득 = 월 납부액 / 3.595%, 이후 같은 방식 (연 환산 x 95%) [측정: s07, s09].
- 카드사용액: 신고소득 = 연 카드사용액 / 40.9%, 추정소득 = 신고소득 x 90% (s10: 3,000만원 → 73,349,633 → 66,014,670) [측정: s10, s12].
- 기타 소득: 추정소득 = 신고소득 x 90% (s11: 5,000만원 → 45,000,000) [측정: s11].
- 5천만원 상한: "상한적용 50,000,000" 행이 나오는 표본(s03, s04, s07, s10)에서도 추정소득 값은 상한을 넘은 채로 표시된다 [측정: s03 68,796,000, s07 63,421,419, s10 66,014,670]. 같은 금액인데 직장 소득자 체크를 하면(s08) 상한 행이 없다 [측정: s07 대 s08].
- 직장 소득자 체크와 기준연도(2025, s13)는 결과를 바꾸지 않았다 [측정: s06 대 s01, s13 대 s01, s08 대 s07 값 동일].
- 월 납부액 0 이면 전부 0 [측정: s05].

## 3. 상수·구간표
- 국민연금 환산률 9.5% [측정: s01 비고], 건강보험료율 3.595% [측정: s07 비고], 카드사용액 환산 40.9% [측정: s10 비고].
- 인정비율: 인정 소득 95%, 신고 소득 90% [측정: s01, s10 비고].
- 상한 5천만원 [측정: s03 비고 문구]. 국민연금 기준소득월액 상·하한 부근 값 573,300원(s03), 36,000원(s02)에서 환산식이 달라지는 흔적은 없음 [측정: s02 4,320,000 = 36,000/9.5% x 12 x 95%].
