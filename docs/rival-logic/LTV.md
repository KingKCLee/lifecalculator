# LTV
- 그쪽 주소: https://부동산계산기.com/ltv  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /LTV계산기 (약한 대응: 출력 방향이 다름)  · 판정: 못찾음

## 1. 입력 항목
- 대출 희망금액·담보가치·선순위채권·임차보증금: 만원. 지역(서울/수도권/광역시/기타), 부동산유형(아파트/기타 주택/상가), 방 공제 체크, 방 수, 임대 중 체크. [측정: s01~s10 요청]
- 우리 쪽 입력: 주택 가격(시세), 규제지역(비규제/조정/투기), 주택 수, 우대 조건(생애최초/서민실수요자), 기존 담보대출 잔액. 대출 희망금액 입력은 없음. [측정: 우리 s01 화면 텍스트]

## 2. 계산식 정리
서버 계산 [추측: 입출력으로 추정한 식].
- LTV = (대출금 + 임차보증금 + 선순위채권 + 최우선변제금액) / 담보가치 x 100 [측정: s07 (2.5억+1억)/5억 = 70%, s08 (2억+0.5억)/5억 = 50%, s10 응답 비고].
- 최우선변제금액 = 방 수 x 지역별 소액보증금 (s10: 서울 3개 x 5,500만원 = 1.65억, LTV 93%) [측정: s10]. 방 수를 비우면 0 (s01) [측정].
- 담보가치 0 이면 LTV 0% 로 표시 (대출 3억이어도) [측정: s11].
- 이 계산기는 지역·유형별 한도와 비교하는 판정 문구를 응답에 주지 않았다. [측정: 12표본 응답 행에 판정 행 없음]

## 3. 상수·구간표
- 서울 소액보증금 55,000,000원/방 [측정: s10]. 다른 지역 값은 이 key 표본에 안 나옴.
- 지역 선택(서울/수도권/광역시/기타)이 LTV 수치를 바꾸지 않음: 같은 비율 입력(80%)에서 광역시(s04)·기타(s05) 모두 80% [측정: s04, s05].

## 5. 우리 같은 입력 결과 및 대조
우리는 대출 희망금액 입력이 없고 "그 가격에서 받을 수 있는 최대 대출"을 낸다. 같은 양이 아니라서 값 대 값 비교가 되지 않는다.
| 표본 | 그쪽 | 우리 | 일치? |
|---|---|---|---|
| s01 | LTV 60% (대출 3억) | 적용 LTV 70%, 최대 대출 350,000,000 | 비교불가(다른 양) |
| s07 | LTV 70% (선순위 1억 + 신규 2.5억) | 적용 LTV 70%, 최대 3.5억 - 기존 1억 = 250,000,000 | 비교불가(다른 양, 경계는 서로 맞음) |
| s11 | LTV 0%, 계산됨 | 필수 입력 안내, 0원 | 비교불가(검증 방식 다름) |
| s12 | LTV 40% (대출 12억) | 최대 대출 1,050,000,000 (9억 초과분 20% 적용) | 비교불가(다른 양) |
(우리 값: [측정: ours-capture/runs/ltv/<표본>.json])

## 6. 판정과 불일치 예시
- 같은 양을 내는 표본이 없어 판정은 못찾음(R3). 불일치도 일치도 주장하지 않는다. [측정: 위 표]
- 방향이 다른 점: 그쪽은 대출 희망금액 -> 비율, 우리는 가격 -> 한도 [측정: 양쪽 화면]. 우리 코드는 App.jsx:2990 CalcLTV. 한도 쪽 비교는 "대출가능액" 문서(LTV계산기 대응)에서 다룬다.
- 참고: s07 은 우리 한도(3.5억 중 기존 1억 차감 = 신규 2.5억)와 그쪽 70% 가 같은 경계를 가리킨다 [측정: s07 양쪽].

## 7. 못 찾음·미확인
- 4개 우리 표본 전부 비교 불가. 그쪽 s02~s06, s08~s10 은 우리에 대응 입력(대출 희망금액, 유형, 임차보증금, 방 공제)이 없어 ours 표본을 만들지 않음. [측정: notes/ltv.md]
- 그쪽 서버가 지역·유형별 한도를 어디에도 쓰지 않는 이유는 모름(응답에 한도 행 없음).
