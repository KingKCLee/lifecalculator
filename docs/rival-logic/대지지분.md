# 대지지분
- 그쪽 주소: https://부동산계산기.com/대지지분  · 계산 위치: 브라우저  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /대지지분계산기 (면적 비례 추정 모드와 대응)  · 판정: 불일치

## 1. 입력 항목
- 토지 면적(#space, ㎡), 대지권 비율 분모(#denominator), 분자(#numerator). 셋 다 채워지면 결과가 나온다. [측정: notes/대지지분.md, 표본 screen.values]
- 우리: 계산 방식 토글(등기부 대지권 비율 / 면적 비례 추정). 면적 비례 추정은 단지 전체 대지면적, 내 전용면적, 단지 전체 전용면적 합계, 매매가(선택). [측정: ours 표본 화면 s01]
- 대응: 토지면적->단지 대지면적, 분자->내 전용면적, 분모->전체 전용면적 합계 (수식이 같아 매핑) [측정: notes/대지지분.md].

## 2. 계산식 정리
- 그쪽: 대지지분(㎡) = 토지면적 x 분자 / 분모, 평 = ㎡ / 3.305785, 둘 다 소수 2자리 [측정: s01 25000x84.9/60000 = 35.38㎡, 10.70평; s10 3.305785 -> 1.00평].
- 칸 값이 문자열 "0"이면 참으로 취급되어 분모 0 이 그대로 나눗셈에 들어가 Infinity 가 표시된다 [측정: s04 .share="Infinity"]. 분모 칸이 비면 결과도 빈 칸 [측정: s12].
- 우리: 대지 x 전용 / 전체 전용합, 전체 합이 0 이하면 0. 평은 ㎡ x 121/400 [측정: ours s04 0.00, s08 302500.01평 (= 1000000x0.3025)].

## 3. 상수·구간표
- 1평 = 3.305785㎡ (그쪽 s10 에서 3.305785㎡가 정확히 1.00평). 법령 근거: 구분소유자의 대지사용권 비율은 전유부분 면적 비율이 기본이다(집합건물의 소유 및 관리에 관한 법률 제12조제1항·제21조제1항, 규약으로 달리 정할 수 있음) [측정: law.go.kr 원문, law/대지지분.json].

## 6. 판정과 불일치 예시
- 판정: 불일치 (비교 12건 중 11건 일치, 1건 불일치). 평 환산 상수가 달라도 소수 2자리 표시에서는 12건 모두 같다.
- 불일치 예시: 토지면적 100, 분모 0, 분자 5 -> 그쪽 대지지분 Infinity㎡ vs 우리 0.00㎡. 원인: 그쪽은 분모 0 을 막지 않고 나누고, 우리는 전체 합이 0 이하면 지분을 0 으로 둔다(CalcLandShare.jsx 의 allArea<=0 처리, notes/대지지분.md 인용) [측정: s04].
- s12 는 양쪽 모두 계산하지 않지만 우리는 0.00㎡ 카드를 함께 보인다(표시 방식 차이).
