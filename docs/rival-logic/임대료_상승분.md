## 1. 입력 항목
- 계산 방식 calcType: 전월세전환 방식(transform, 기본) / 환산보증금 방식(conversion) [측정: rival-capture/html/임대료상승분.html:779, 표본 s07, s09]
- 물건 구분 realEstateType: 주택(house) / 상가(retail) [측정: 임대료상승분.html:780, 1331-1336, s08]
- 보증금 deposit, 월차임 rent (단위 만원, 요청에 입력 숫자가 그대로 가고 응답은 원 단위) [측정: s01 요청·응답]
- 상승률 increaseRate (%, 기본 5; 입력칸 안내문구는 "만원 단위 금액"으로 잘못 적혀 있으나 값은 %로 쓰였다) [측정: 임대료상승분.html:817, s04~s06, s13]

## 2. 계산식 정리
- 서버 계산이라 식은 응답 값으로 추정한 것이다 [추측].
- 전월세전환 방식(주택): 전세보증금으로 전환 = 보증금 + 월차임 x 12 / 5.5%. 예: 1억 + 50만 x 12 / 0.055 = 209,090,909 [측정: s01 값 209,090,909; 5.5%는 값에서 거꾸로 맞춘 숫자 [추측]]
- 전환보증금 인상 = 전환한 값 x (1 + 상승률). s01: 209,090,909 x 1.05 = 219,545,455, s06(10%): 230,000,000 [측정]. 상승률을 5%로 제한하지 않고 입력 그대로 쓴다 [측정: s06].
- 월차임 상한선 = (인상된 전환보증금 - 기존 보증금) x 5.5% / 12. s01: (219,545,455 - 100,000,000) x 0.055 / 12 = 547,917 [측정: s01 값, 계산은 문서 작성자]
- 환산보증금 방식: 환산보증금 = 보증금 + 월차임 x 100 (s07: 5,000만 + 300만 x 100 = 350,000,000; s09: 1억 + 50만 x 100 = 150,000,000) [측정]. 인상 = x (1 + 상승률), 월차임 상한선 = (인상 후 환산보증금 - 보증금) x 12% / 12 (s09: 57,500,000 x 0.12 / 12 = 575,000) [측정: s09 값]
- 상가를 전월세전환 방식으로 계산하면 전환율이 12%로 보인다 (s08: 300만 x 12 / 0.12 + 5,000만 = 350,000,000) [측정: s08 값, 12%는 [추측]]

## 3. 상수·구간표
- 주택·전월세전환 방식의 전환율: 값으로 거꾸로 맞춰 5.5% [추측: s01, s02, s10 값이 모두 이 비율로 설명됨]
- 환산보증금 방식·상가 전환율: 12% (월차임 x 100) [측정: s07, s08, s09, s12 값]
- 상승률 입력 상한: 10%, 5.5%(소수)도 그대로 계산됨 [측정: s06, s13]
- 월차임 0·보증금 3억일 때 월차임 상한선은 68,750 (s03): (315,000,000 - 300,000,000) x 5.5% / 12 [측정: s03 값]

## 6. 판정과 불일치 예시
- 판정: 불일치 (4/11). [측정: rival-capture/runs/임대료상승분/ 와 ours-capture/runs/임대료상승분/ 같은 id]
- 불일치 예시: 주택, 보증금 1억 + 월차임 50만원, 상승률 5% -> 그쪽 인상 후 전환보증금 219,545,455원 vs 우리 최대 환산보증금 231,000,000원 [측정: s01 양쪽 결과].
- 원인(우리 코드 읽기): 우리는 환산보증금 = 보증금 + 월세 x 12 / 입력 전환율 (src/calcs/CalcRentIncrease.jsx:17)이고 전환율 입력칸에 5를 넣었다. 그쪽 주택 전환 방식은 값으로 보아 5.5%를 쓰는 것으로 보인다 [추측]. 그래서 월차임이 있는 주택 전환 방식 표본은 모두 어긋나고, 월차임이 0인 s03 과 12%·x100 환산 방식 표본(s07, s09, s12)은 전환율 차이가 없어 일치했다 [측정: 표 대조].
- 의미가 다른 항목(표 밖): 그쪽 "월차임 상한선"은 인상된 전환보증금에서 기존 보증금을 뺀 몫을 월차임으로 바꾼 값(s01 547,917)인 반면 우리 "B. 월세만 인상 시 최대"는 월세 x (1 + 한도) (App 아님, CalcRentIncrease.jsx:23)로 525,000 이다 [측정: s01 양쪽 결과].
- 상승률 10%(s06): 그쪽도 5%로 줄이지 않고 그대로 계산했고, 우리도 그대로 계산했다 [측정].

## 7. 못 찾음·미확인
- s08(상가 + 전월세전환 방식): 우리에 상가 전환율 기능이 없어 제외.
