# 장래 소득
- 그쪽 주소: https://부동산계산기.com/장래소득  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /장래소득계산기 (id futureincome)  · 판정: 불일치

## 1. 입력 항목
- 연소득: 단위 만원, 숫자 직접 입력 (id income, placeholder "만원 단위로 숫자만") [측정: rival-capture/html/장래소득.html:817]
- 나이: 단위 세, 숫자 직접 입력 (id age) [측정: rival-capture/html/장래소득.html:830]
- 대출 만기: 단위 년, 자유 숫자 입력 (id maturity) [측정: rival-capture/html/장래소득.html:843]
- 계산 버튼은 서버 함수 호출(doTran futureIncome)이며 브라우저에서 식을 계산하지 않는다 [측정: rival-capture/html/장래소득.html:852]
- 우리 쪽은 연소득(만원)·만 나이(세)·만기 선택(10/15/20/30년 이상 4개)이다 [측정: ours-capture/runs/장래소득/s01.json 화면 값, src/calcs/CalcFutureIncome.jsx:23-25]

## 2. 계산식 정리
- 서버 계산이므로 아래는 입출력으로 추정한 식이다 [추측].
- 만 20~34세, 만기 10년 이상일 때만 증가율이 나온다 [측정: s02, s07, s08, s10, s11, s13 응답]. 35세 이상·19세는 "적용 대상 연령이 아님" 문구가 오고 증가율이 비어 있다 [측정: s08, s09, s10, s13]. 만기 9년은 "해당 만기 내 적용 가능한 증가율 없음" [측정: s11].
- 연령 구간(20~24, 25~29, 30~34)과 만기 열(10, 15, 20, 30년)이 곱해진 표에서 증가율을 읽는다 [추측].
- 만기 N년 입력 시 표의 10/15/20/30 열 중 N 이하인 열만 보여주고 그중 가장 큰 증가율을 "가장 유리한 증가율"로 고른다 [측정: s03 만기 20 → 3열 중 39.7, s12 만기 25 → 20년 열까지 3열 중 28.4, s07 만기 30 → 4열 중 20년 열 18.4].
- 장래 추정 소득 = 연소득 × (1 + 증가율) [측정: 응답 비고 문구, s01 36,000,000 × 1.316 = 47,376,000].
- 각 열의 비고에 "3개/4개/5개/7개 연령 평균 ÷ 현재 소득"이라고 적혀 있어 만기 길이만큼의 연령별 소득 평균과 현재 소득의 비율일 가능성이 있다 [추측: s01 응답 비고].
- 근거 문구는 "가계대출 모범규준에 따르면 만기 이내에서 가장 유리한 소득증가율 선택 가능" 이다 [측정: s01 basis].

## 6. 판정과 불일치 예시
- 판정: 불일치. 원인은 두 갈래다.
- 원인 1, 인정률 표 값: 우리 표는 25~29세 30년 열 31.4, 30~34세 20년 열 17.7, 30년 열 13.1 이다 [측정: src/calcs/CalcFutureIncome.jsx:8-10]. 그쪽 관찰값은 31.6, 18.4, 13.5 이다 [측정: s01, s06, s07]. 나머지 칸(20~24세 10/15/20년, 25~29세 10/15/20년, 30~34세 10/15년)은 양쪽 같다 [측정: s02~s06].
- 원인 2, 대상 연령 처리: 우리는 35~44세에 "0%로 둠" 안내, 19세·45세에 "20~44세 대상" 안내를 내고 인정소득을 현재 소득 그대로 보여준다 [측정: CalcFutureIncome.jsx:28, s08~s10, s13 화면]. 그쪽은 20세 이상 35세 미만만 가능하다고 한다 [측정: s08 basis].
- 만기 30년 이상 선택 시 우리는 20년 열과 30년 열 중 큰 값을 쓴다 [측정: CalcFutureIncome.jsx:19]. 그쪽도 열 중 최대값을 고른다 [측정: s07]. 이 부분 구조는 같다.
- 불일치 예시: 연소득 3,600만원 · 만 28세 · 만기 30년 → 그쪽 47,376,000원(31.6%) vs 우리 47,304,000원(31.4%).
- 불일치 예시 2: 3,600만원 · 만 30세 · 만기 20년 → 그쪽 42,624,000원(18.4%) vs 우리 42,372,000원(17.7%).

## 7. 못 찾음·미확인
- s11(만기 9년), s12(만기 25년)는 우리 만기 선택지(10/15/20/30년 이상)에 없어 우리 쪽을 실행하지 않았고 비교에서 뺐다 [측정: ours-capture/runs/장래소득/ 에 s11·s12 파일 없음].
- 그쪽 s01~s13 전부 status ok, success true 이며 제외한 그쪽 표본은 없다 [측정].
- 20~24세 30년 열(우리 51.6%)은 그쪽 값을 측정하지 못했다 [측정: 해당 표본 없음].
- 연령별 소득 평균을 어떤 통계로 만드는지, 표 갱신 시점은 응답에 없어 모름 [추측 아님, 못 찾음].
