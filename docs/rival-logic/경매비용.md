## 1. 입력 항목
- 유형: 일반 부동산(etc) / 아파트(apt) [측정: s01, s11]
- 기준금액(amount, 만원), 채권금액(security, 만원), 이해관계인 수(stakeholder, 명), 목적물 수(targetCnt, 개) [측정: rival-capture/html/경매비용.html, 요청값]
- 역전 입력(채권금액 > 기준금액)도 거부하지 않고 계산 [측정: s13]. 전부 0 도 계산함 [측정: s02].

## 2. 계산식 정리
서버 계산이며 아래는 응답 비고와 값으로 추정한 식이다 [추측].
- 등록면허세 = 채권금액 x 0.2% [측정: 응답 비고, s01 5천만 -> 100,000]. 지방교육세 = 등록면허세 x 20% [측정: 비고, s01 20,000].
- 송달료 = (이해관계인 수 + 3) x 10회 x 5,200원 [측정: 비고; s01 312,000, s10 20명 1,196,000, s02 0명 156,000].
- 등기신청수수료 = 목적물 수 x 3,000원 [측정: 비고; s09 5개 15,000].
- 신청비용 소계 = 등록면허세 + 지방교육세 + 송달료 + 등기신청수수료 [측정: s01 100,000+20,000+312,000+3,000 = 435,000. 비고 문구에는 지방교육세가 빠져 있으나 값에는 포함됨].
- 감정료 소계 = (감정평가수수료 + 실비) x 1.1 [측정: 비고; s01 (240,000+48,000) x 1.1 = 316,800].
- 현황조사수수료 = 70,000 고정 [측정: 모든 표본]. 신문공고료 = 220,000 + 2건 초과분 건당 110,000, 건수는 목적물 수로 보임 (s09 5개 -> 550,000) [측정: s09; 건수=목적물 수는 추정 [추측]].
- 매각수수료 = 기준금액 구간별 (아래 3번). 예납금 소계 = 감정료 + 현황조사 + 신문공고 + 매각수수료 [측정: s01 1,909,800].
- 총계 = 신청비용 소계 + 예납금 소계 [측정: s01 2,344,800].

## 3. 상수·구간표 (표본에서 관찰된 값만)
- 매각수수료 [측정]: 10만 이하 5,000 (s02) / 10만~1천만 203,000 (1천만, s03) / 1천만~5천만 803,000 (5천만, s04) / 5천만~1억 1,303,000 (1억, s01; 응답 basis 에 (기준-5천만) x 1% + 803,000) / 1억 초과~3억 (1억+1만원 -> 1,303,050, s05) / 3억~5억 2,903,000 (5억, s06) / 5억~10억 3,903,000 (10억, s07) / 10억 초과 3,903,000 (s08, s15). 각 구간 안의 비율은 값 몇 개로 맞춰 본 추정이다 [추측].
- 감정평가수수료·실비(일반 부동산) [측정]: 기준 140,909,090원 이하 240,000 / 실비 48,000 (s01, s03, s04, s05). 5억 -> 556,000 / 88,000 (s06), 10억 -> 916,000 / 88,000 (s07), 50억 -> 3,476,000 / 88,000 (s08), 9,507,142,857원 초과 -> 6,000,000 / 88,000 (s15). 구간 경계 사이는 못 찾음.
- 아파트: 1억에서 일반과 같은 240,000이나 경계 문구가 179,870,129원 (s11), 5억에서 486,500 (일반은 556,000) (s12) [측정].

## 7. 못 찾음·미확인
- 비교 표본 0건 (우리에없음). 그쪽 15개 표본은 모두 status ok, 거부 응답 없음 [측정].
