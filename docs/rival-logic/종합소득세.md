# 종합소득세
- 그쪽 주소: https://부동산계산기.com/종합소득세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /종합소득세계산기 (부분 대응: 사업소득+실제 경비 입력 모드로 매핑)  · 판정: 불일치

## 1. 입력 항목
- 임대 소득·다른 소득·경비·기타 소득공제·기타 세액공제: 만원 단위. 부양가족(배우자 포함): 명. 자녀(세액공제용): 명 [측정: 종합소득세.html:783,822,833,847,858 입력칸 id와 안내문].
- 화면에 없고 요청에만 실리는 값: register=N, realEstate=house, record=Y [측정: 표본 s01 요청].
- 우리 쪽 입력: 소득 유형 4종, 총수입금액, 경비 방식, 필요경비, 배우자(최대 1), 60세 이상 부모, 20세 이하 자녀, 경로우대, 장애인 [측정: App.jsx:3379-3381].
- 매핑(우리 화면에 넣은 값): 총수입금액=임대+다른소득, 필요경비=경비, 배우자=min(부양가족,1), 부모=부양가족-1, 자녀=자녀 [측정: specs/ours/종합소득세.json 표본 노트].

## 2. 계산식 정리
서버 계산이라 코드는 보이지 않고, 응답 행에서 아래 식이 읽힌다 [추측: 입출력으로 추정한 식].
- 종합소득 = 임대 + 다른소득 - 경비, 0 미만이면 0 (s11: 3000-4000 → 0) [측정: s11 응답].
- 과세표준 = 종합소득 - 본인공제 150만원 - 부양가족수×150만원 - 기타 소득공제, 0 미만이면 0 [측정: s02, s08, s12 응답 행].
- 산출세액 = 과세표준 × 누진세율 - 누진공제액 [측정: 응답 비고 문구].
- 결정세액 = 산출세액 - 표준 세액공제 7만원 - 자녀 세액공제 - 기타 세액공제 (0 미만은 0) [측정: s03, s08, s12 응답 행].
- 자녀 세액공제는 1명 15만원, 2명 30만원으로 관찰됨. 3명 이상은 표본 없음 [측정: s08, s09].
- 지방소득세는 응답에 없음 [측정: 전 표본 응답 행].

## 3. 상수·구간표
관찰된 구간 [측정: 응답 비고]: 1,400만 이하 6% / 1,400만~5,000만 15%(공제 126만) / 8,800만~1.5억 35%(공제 1,544만) / 3억~5억 40%(공제 2,594만) / 10억 초과 45%(공제 6,594만).
관찰 못 한 구간: 5,000만~8,800만 24%, 1.5억~3억 38%, 5억~10억 42% — s06 과세표준 5,000만, s07 8,800만 경계 표본은 있으나 해당 구간 내부 표본은 없음 [측정: 표본 목록]. 계수는 우리 쪽 표 IB(App.jsx:523, 3153)와 같은 값을 사용한다고 추정 [추측].
표시 이슈: s10 비고가 "10억원 초과 0원 이하 45%"로 표기됨(상한 0원 표시) [측정: s10 응답].

## 6. 판정과 불일치 예시
판정: 불일치 (비교 12건 중 10건 일치).
- 불일치 원인은 자녀 입력 해석 차이다. 우리는 자녀 수를 기본공제 인원에도 더한다(App.jsx:3386, basicDed=(1+배우자+부모+자녀)×150만원). 그쪽은 자녀 칸을 세액공제 전용으로 쓰고 기본공제는 부양가족 칸 수만 쓴다 [측정: s08 응답에 부양가족 공제 3,000,000과 자녀 세액공제 150,000이 따로 있음].
- 예시: 임대5000·다른소득6000·경비1000·부양가족2·자녀1(만원·명) → 그쪽 결정세액 17,765,000원(과세표준 95,500,000) vs 우리 17,240,000원(과세표준 94,000,000, 기본공제 4명 6,000,000원).
- 같은 과세표준 95,500,000원 에 우리 세율표를 적용하면 산출세액 17,985,000원으로 그쪽과 같다 [측정: 응답 행과 App.jsx:523 계산식 대조, 손계산].
- 화면 대표값 차이: 우리는 큰 숫자로 지방소득세 10%를 더한 합계를 보여준다(App.jsx:3389). 그쪽은 결정세액까지만 [측정: s01 우리 3,239,500원 vs 그쪽 2,945,000원].
- 양쪽 공통: 자녀 세액공제 1명 15만원, 2명 30만원(우리 App.jsx:3388). 현행 법령 금액과의 대조는 조문 원문을 받지 못해 못 함(7번).
