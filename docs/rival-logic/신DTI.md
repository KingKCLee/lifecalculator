# 신DTI
- 그쪽 주소: https://부동산계산기.com/신DTI  · 계산 위치: 서버  · 측정일: 2026-10-15 [측정:라이브 부동산계산기.com]
- 우리 대응: /DTI계산기 (일부 대응: 신DTI 값 = 신규 원리금 + 기존 원리금, 신규 1건만)  · 판정: 못찾음 — 그쪽 응답 없음 (성공 표본 1/12, 그 1건은 우리와 비교 불가)

## 1. 입력 항목
- /신DTI 는 /DSR 과 같은 폼이다 (폼 영역 문자열 동일, 계산 API 동일). 연소득(만원), 대출 행(종류·상환방식·금리·금액 3칸·기간 3칸), 기준일자·초년도 이자 기준·장래소득(나이) 선택. 신DTI 탭이 숨은 값 dcd=newdti 를 보낸다. [측정: notes/신DTI.md, s04 요청]
- 우리 입력: DTI 계산기의 연소득, 신규 대출금액, 금리, 기간, 기존 대출 월이자 합계, 기존 대출 월 원금상환액(신DTI용). [측정: ours-capture/runs/신DTI/s01 화면 텍스트]

## 2. 계산식 정리
- 그쪽: 응답 근거 문단이 "주택담보대출은 원리금 상환액을 모두 더하고 그 외 대출은 이자만 더하여 부채를 산정" 하고 "잔여 기간 동안의 평균 연원리금상환액" 을 쓴다고 적는다. [측정: s04 basis]
- s04 에서 신용대출 5,000만원(만기일시 12개월 5%)은 연 원금 상환액 0, 연이자 2,500,000원, 신DTI = 2,500,000 / 50,000,000 x 100 = 5% 였다. 식 전체(주담대 포함)는 이 한 건만으로 확정하지 못했다. [측정: s04 응답]
- 우리: 신DTI = (신규 원리금 + 기존 원리금) / 연소득 x 100, 기존 원금은 사용자가 입력한 월 원금상환액 합계를 대출 종류 구분 없이 더한다. 구 DTI 는 신규 원리금 + 기존 이자. [측정: 우리 s01 화면 "신규원리금+기존원리금", notes/신DTI.md]

## 3. 상수·구간표
- 그쪽: 관찰된 규제 구간 없음. 우리 화면은 40/50/60% 판정을 따로 표시한다. [측정: 우리 s01 화면]
