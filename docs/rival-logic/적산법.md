## 2. 계산식 정리
서버 계산이며 응답 비고의 식.
- 기대수익 = 기초가액 × 기대이율 — s01: 1,000,000,000×3% = 30,000,000 [측정]
- 연 적산임료 = 기대수익 + 연간 필요제경비 — s01: 35,000,000 [측정]
- 월 적산임료 = 연 적산임료 ÷ 12 — s01: 2,916,667 [측정]
- 보증금이 있으면: 보증금 운용수익 = 보증금 × 운용이율, 월 임료 = (연 적산임료 − 보증금 운용수익) ÷ 12 — s08: (35,000,000−3,000,000)÷12 = 2,666,667 [측정]. 보증금이 기초가액을 넘는 s10 에서 월 임료가 −83,333원으로 음수가 그대로 나옴 [측정]
- 입력 검증: 기대이율 0, 기초가액 0 이면 거부 — s03, s05 [측정]
- 우리 식(CalcAppraisalMethods.jsx:93): 적산임료(연) = 기초가액 × 기대이율÷100 + 필요제경비, 월 환산 = ÷12 [측정: 코드 읽기]. 보증금 차감은 없고 나머지 식은 같다.
