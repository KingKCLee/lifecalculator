# 환산임대료(NOC)
- 그쪽 주소: https://부동산계산기.com/noc  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /환산임대료계산기 (src/calcs/CalcNoc.jsx) — 일부만 겹침  · 판정: 일치

## 1. 입력 항목
- 면적 단위 unit: 평(pyung, 기본) / 제곱미터(squareMeter), 면적 area [측정: rival-capture/html/noc.html 의 입력칸, 표본 s01, s02 요청]
- 보증금 deposit, 월 임대료 rent, 월 관리비 maintenanceCost (단위 만원) [측정: s01 요청과 응답 원 단위 값]
- 금리 직접입력 체크(customRate=on) 후 rate(%); 체크하지 않으면 요청에 rate=3.1 이 같이 간다 [측정: s08 요청]
- 기타 차감액 체크(etcSubtractYn=Y) 후 subtract(만원, 음수도 받음), monthSubtract(월 차감액, 입력칸 단위 표기 불명) [측정: s12, s13 요청]

## 2. 계산식 정리
- 서버 계산이라 식은 응답 값과 화면 안내 문구로 추정한 것이다 [추측].
- 보증금 이자(연) = 보증금 x 금리, 보증금 이자(월) = 연 이자 / 12. 5,000만 x 6% = 3,000,000 / 12 = 250,000 [측정: s01]
- 총 월 비용 = 보증금 월 이자 + 월 임대료 + 월 관리비. 250,000 + 3,000,000 + 300,000 = 3,550,000 [측정: s01, 비고 문구 "보증금 월 이자 + 월세 + 월 관리비"]
- 환산 임대료(NOC) = 총 월 비용 / 면적. ㎡ 선택이면 ㎡당(66㎡: 3,550,000 / 66 = 53,788), 평 선택이면 평당(20평: 3,550,000 / 20 = 177,500) [측정: s01, s02; 나눗셈은 문서 작성자]. 응답의 단위 표기는 "(만원)" 이지만 값은 원 단위다 [측정: s01 응답 비고].
- 기타 차감액을 넣으면 총 월 비용에서 차감액 월 환산분(차감액 / 12)을 뺀다. 400만원 -> 333,333 [측정: s12]. 음수 -100만원은 83,333 이 더해진다 [측정: s13].
- 화면 안내 문구는 같은 식을 {보증금 x 시장 금리 + 월 임대료 + 월 관리비} / 전용면적 으로 적고 있다 [측정: rival-capture/html/noc.html:778, 780].

## 3. 상수·구간표
- 금리 미입력 기본값 3.1% (시장 금리로 쓰임): 보증금 5,000만 -> 월 이자 129,167 [측정: s08]
- 면적이 1㎡이면 총 월 비용이 그대로 NOC (3,550,000) [측정: s10]
- 입력 오류 메시지: 보증금 0 "보증금 입력해주세요!", 월 임대료 0 "월세를 입력해주세요!", 면적 0 "면적을 입력해주세요!" [측정: s03, s04, s11]
- 상수·세율표는 없다 (순수 산술식).

## 5. 우리 같은 입력 결과 및 대조
비교 항목은 "총 월 비용"(그쪽) 대 "최종 환산 월임대료"(우리)이다. 면적당 값은 그쪽이 ㎡ 또는 평 선택에 따르고 우리는 평당만 보여준다(src/calcs/CalcNoc.jsx:26). 그래서 ㎡ 표본은 우리 평당 값을 3.305785로 나눈 ㎡당 값으로 바꿔 그쪽 NOC 와 맞췄다(나눗셈은 문서 작성자가 계산, 소수점 반올림 후 정수 일치). s02 는 평 표본이라 우리에 20평을 66.1157㎡로 넣었다 [측정: specs/notes/noc.md].

## 6. 판정과 불일치 예시
- 판정: 일치 (8/8). [측정: rival-capture/runs/noc/ 와 ours-capture/runs/noc/ 같은 id] 우리 식은 월세 + 관리비 + 보증금 x 전환이율 / 12 (src/calcs/CalcNoc.jsx:25)로 그쪽 총 월 비용과 같고, 평당 값은 총액 / (㎡ / 3.305785)이다 (CalcNoc.jsx:26).
- 불일치 예시: 비교한 표본에는 없다. 다만 표시 단위가 다르다: 66㎡ 보증금 5,000만 월 300 관리비 30 금리 6% -> 그쪽 NOC 53,788원(㎡당) vs 우리 평당 환산 월임대료 177,811원이며, 총 월 비용은 둘 다 3,550,000원이다 [측정: s01 양쪽 결과].
- 우리에만 있는 것: 환산보증금(보증금 + 월세 x 100)과 지역별 상가임대차보호법 적용 판정, 연간 환산 임대료 [측정: 우리 화면].
- 그쪽에만 있는 것: 평/㎡ 단위 선택, 기타 차감액·월 차감액 입력 [측정: specs/notes/noc.md]. 이 둘은 우리에 해당 입력이 없어 비교하지 않았다.
- 면적 0일 때: 그쪽은 오류 문구를 내고 우리는 총액은 계산하고 평당 값 칸에 "면적 입력 시 표시"를 보여준다 [측정: s11 양쪽 화면].

## 7. 못 찾음·미확인
- s03(보증금 0), s04(월세 0), s11(면적 0): 그쪽이 오류 응답을 줘서 비교 표에서 뺐다. (우리는 s03 에서 환산 월임대료 3,300,000 을, s04 에서 500,000 을 계산해 보여준다 [측정].)
- s12, s13(기타 차감액): 우리에 입력이 없어 제외.
- 그쪽 monthSubtract(월 차감액) 입력의 의미는 표본이 없어 못 찾음.
- 그쪽 식은 서버 계산이라 코드를 볼 수 없다. 위 식은 [추측]이다.
