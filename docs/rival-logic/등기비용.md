# 등기비용
- 그쪽 주소: https://부동산계산기.com/등기비용  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /등기비용계산기 (App.jsx CalcReg)  · 판정: 불일치

## 1. 입력 항목
- 부동산 종류(realEstateType): 주택 / 오피스텔 / 기타 토지 등 [측정: s01, s13, s14 요청값]
- 면적 구분(areaType=85), 지역(regionType=seoul 등), 주택수(own=one) [측정: 요청값]
- 거래금액(amount), 시가표준액(standardPrice), 토지 시가표준액(landStandardPrice) — 모두 만원 단위 [측정: s01, s14]
- 체크 항목: 셀프등기(self=Y, s12), 법인(corporation=Y, s15) [측정: 요청값]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 총계 = 취득세 합계 + 채권할인료 + 보수액 소계 + 공과금 소계 [추측: s01 합 550,000+147,127+531,000+18,000=1,246,127 이 총계와 같음, 측정된 산술 일치]
- 취득세 합계 = 금액 x (취득세율 + 지방교육세율 [+ 농특세율]) [측정: s01 1%+0.1% -> 550,000, s13 4%+0.4%+0.2% -> 23,000,000]
- 주택 6~9억은 취득세율을 금액 구간 식으로 잇는다는 설명이 basis에 있다 [측정: s09 basis 문구, 지방세법 제11조 1항 8호 인용]
- 채권매입금액 = 시가표준액 x 지역·종류·구간별 매입률 (s01 5천만대 0.019 등 basis에 구간 명시), 채권할인료 = 매입금액 x 할인율(주택도시기금 공시 최신값) [측정: basis 문구 / 할인율 숫자는 응답에 안 보임 -> 식은 추측]
- 법무사 보수는 금액 구간별 기본보수 + 부가세 10% + 대행료 3종(5만/5만/4만) + 일당 8만 + 교통실비 8만 [측정: s01~s11 항목]
- 공과금 = 수입증지 18,000 + 수입인지(1억 초과 15만, 10억 초과 35만) [측정: s03/s04, s10/s11]

## 3. 상수·구간표
- 취득세: 서울 85㎡ 이하 1주택 6억 이하 1%, 10억 3% (s10) / 법인 12% (s15) / 오피스텔·토지 4%+0.4%+농특 0.2% (s13, s14) [측정]
- 채권 매입률(서울·광역시 주택): 5천~1억 0.019, 1~1.6억 0.021, 1.6~2.6억 0.023, 2.6~6억 0.026, 6억 이상 0.031 [측정: s01~s08 basis]. 그 외 지역·종류 표는 확정 못 함.
- 법무사 등기 보수: 5천만 210,000 / 1억 260,000 / 1.6억 314,000 / 3억 440,000 / 6억 670,000 / 10억 950,000 / 오피스텔 5억 600,000 / 토지 5억 950,000 [측정: s01~s14]
- 수입인지: 1억 이하 0, 1억 초과 150,000, 10억 초과 350,000 (경계 "초과"가 기준) [측정: s03/s04, s10/s11]

## 6. 판정과 불일치 예시
- 판정: 불일치 (총계 기준 0/13). 취득세 합계만 보면 s01~s09 9건은 같고 s10, s11, s13, s14 4건은 다르다 [측정].
- 불일치 예시: 주택 서울 1주택 10억 -> 그쪽 총계 39,314,001원(취득세 합계 33,000,000원) vs 우리 총계 13,282,000원(취득세 합계 11,000,000원).
- 원인(우리 코드 줄): 취득세율을 매매는 1%로 고정한다 (src/App.jsx:3204 acqR). 6억 초과 주택·오피스텔·토지의 3~4% 구간이 없다 [측정: 코드 읽기]. 채권은 자체 구간표(App.jsx:3205)에 5천만 이하면 0으로 둬서 s01에서 그쪽은 채권 950,000 매입, 우리는 0 [측정: s01]. 채권할인료는 우리가 매입액 x 4.5% 고정, 그쪽은 매입액에 대한 별도 할인율(s01 950,000 매입에 147,127, 약 15.5%)이라 크기가 다르다 [측정: s01 양쪽 값]. 법무사 보수도 구간 금액이 달라 s01에서 그쪽 보수액 소계 531,000 vs 우리 256,000 [측정].
- 우리는 법원수수료 15,000 고정(App.jsx:3207), 그쪽은 수입증지 18,000 [측정].

## 7. 못 찾음·미확인
- s12(셀프등기), s15(법인): 우리 쪽에 입력이 없어 비교 제외.
- 그쪽 채권 할인율의 실제 값은 응답에 직접 나오지 않아 확정 못 함 (매입액 대비 역산만 가능).
- 지역(서울 외)·면적(85㎡ 초과)·주택수(2주택 이상)·생애최초 조합은 표본에 없어 확인 못 함.
- 오피스텔 건물분/토지분 채권 분리 계산(s13)의 세부 식은 못 찾음.
