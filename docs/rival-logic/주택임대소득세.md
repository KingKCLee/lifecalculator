# 주택임대소득세
- 그쪽 주소: https://부동산계산기.com/주택임대소득세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /임대소득세계산기 (App.jsx CalcRental) — 일부만 겹침  · 판정: 불일치

## 1. 입력 항목
- 등록 여부 register: 미등록(N, 기본) / 등록 임대주택(Y) [측정: rival-capture/html/주택임대소득세.html:793, 표본 s08]
- 월세 rent, 보증금 deposit (단위 만원) — 월세는 월 금액이다 [측정: 주택임대소득세.html:812, 823, s01]
- 수입금액 직접입력 체크(totalAmtCheck) 후 연 수입 totalAmt(만원) [측정: 주택임대소득세.html:790, 801, s03]
- 임대기간 period(연) — 등록을 고른 때만 보인다 [측정: 주택임대소득세.html:829-834, s08, s09]
- 숨김값 realEstate=house [측정: 표본 요청 파라미터]

## 2. 계산식 정리
- 서버 계산이라 식은 응답의 항목과 값으로 추정한 것이다 [추측].
- 기준 수입금액 = 월세 x 12 + 간주임대료 (직접입력이면 입력한 연 수입) [측정: s01 12,000,000, s03 4,000,000, s11 10,200,000]
- "필요경비 적용" 항목은 수입에서 경비를 뺀 나머지 금액이다: 미등록 12,000,000 -> 6,000,000 (경비율 50%), 등록 12,000,000 -> 4,800,000 (경비율 60%) [측정: s01, s08]
- 기본공제: 미등록 2,000,000 / 등록 4,000,000 [측정: s01, s08]
- 과세표준 = max(0, 경비 뺀 금액 - 기본공제), 산출세액 = 과세표준 x 14%. 예: 4,000,000 x 14% = 560,000 [측정: s01]
- 세액감면: 등록 임대주택 4년이면 산출세액의 30%를 감면(112,000 -> 78,400), 8년이면 75%를 감면(112,000 -> 28,000) [측정: s08, s09; 감면율은 값에서 계산한 것]
- 간주임대료 = (보증금 - 3억원) x 60% x 3.5% [추측: s10 값 14,700,000 = (10억 - 3억) x 0.6 x 0.035, s11 값 4,200,000 = (5억 - 3억) x 0.6 x 0.035 에 맞춘 식]

## 3. 상수·구간표
- 분리과세 세율 14% [측정: s01, s04, s05]
- 미등록: 필요경비율 50%, 기본공제 200만원 [측정: s01]. 등록: 필요경비율 60%, 기본공제 400만원 [측정: s08]
- 수입 400만원(경비 후 200만원 = 공제) 까지 세액 0, 401만원이면 700원 [측정: s03, s04]
- 수입 2,000만원 초과(2,001만원, 월세 200만원)도 오류 없이 같은 분리과세 식으로 계산된다 [측정: s05, s06, s07]
- 감면: 임대기간 4년 30%, 8년 75% — 4년과 8년 사이, 8년 초과 구간은 표본이 없어 확정 못 함.
- 간주임대료 공제 보증금 3억원·이율 3.5%는 값에서 맞춘 추정이다 [추측].

## 5. 우리 같은 입력 결과 및 대조
비교 항목은 "납부할 세액"(그쪽) 대 "분리과세 임대소득세"(우리)이다. 그쪽 월세는 월 금액이라 우리 "연간 임대수입" 칸에는 x12 한 값을 넣었고, 우리는 경비율·기본공제를 직접 입력한다(미등록 50%/200만원, 등록 60%/400만원) [측정: specs/notes/주택임대소득세.md]. 우리 주택 수 라디오는 기본값(2주택)이다.

## 6. 판정과 불일치 예시
- 판정: 불일치 (7/9). [측정: rival-capture/runs/주택임대소득세/ 와 ours-capture/runs/주택임대소득세/ 같은 id]
- 불일치 예시: 등록 임대주택, 월세 100만원(연 1,200만원), 임대기간 8년 -> 그쪽 납부할 세액 28,000원 vs 우리 분리과세액 112,000원 [측정: s09 양쪽 결과]. 임대기간 4년(s08)도 그쪽 78,400원 vs 우리 112,000원이다.
- 원인(우리 코드 읽기): 우리 분리과세 세액은 max(0, 수입 x (1 - 경비율) - 기본공제) x 14% 까지만 구하고(src/App.jsx:3334) 등록 임대주택 세액감면과 임대기간 입력이 없다. 그쪽 산출세액(s08, s09 모두 112,000원)은 우리 값과 같고, 감면 뒤 금액만 다르다 [측정: 양쪽 결과 대조]. 일치한 7개 표본은 모두 미등록이라 감면이 붙지 않는 경우다.
- 구성 차이(비교 표 밖): 우리는 주택 수 선택, 종합과세 참고액과 유리한 방식 비교, 2천만원 초과 경고문을 보여준다. 그쪽은 보증금 간주임대료(s10, s11)와 임대기간 입력이 있다 [측정: specs/notes/주택임대소득세.md].

## 7. 못 찾음·미확인
- s10, s11(보증금 간주임대료): 우리에 보증금 입력이 없어 비교에서 뺐다.
- s12(월세·보증금 0): 그쪽은 0 을 계산했고 우리는 입력 필요 안내만 나와 비교에서 뺐다.
- 등록 임대주택 감면율의 임대기간별 구간(5~7년, 10년 이상 등)은 표본이 4년·8년뿐이라 못 찾음.
- 그쪽 식은 서버 계산이라 코드를 볼 수 없다. 위 식은 [추측]이다.
