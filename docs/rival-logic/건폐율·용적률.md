# 건폐율·용적률
- 그쪽 주소: https://부동산계산기.com/건폐율용적률  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /용적률건폐율계산기  · 판정: 불일치

## 1. 입력 항목
- 대지 면적(#ground, ㎡)과 건물 N동 x 층별 면적(buildings[동][], ㎡). "층 +/-" 버튼으로 층을 늘리고 건물 추가 아이콘으로 동을 늘린다. [측정: 표본 요청 s01, s06, s08]
- 우리: 대지면적, 건축면적(1층 바닥), 연면적(전체 층 합계), 지하면적 4칸 고정(㎡). 결과 아래에 용도지역별 한도표가 붙는다. [측정: ours 표본 화면, notes/건폐율용적률.md]

## 2. 계산식 정리
서버 계산이라 식은 보이지 않고 응답 비고에 식이 적혀 있다.
- 건폐율 = 건물 1층 면적의 합 / 대지 면적 x 100 (비고 "건물 바닥면적 / 대지 면적 * 100") [측정: s01 응답]. 다동이면 동별 1층의 합(s08 100+80=180) [측정: s08].
- 용적률 = 모든 층 면적의 합 / 대지 면적 x 100 (비고 "연면적 / 대지 면적 * 100") [측정: s06 450/330 = 136.4%].
- 소수 한 자리까지 표시, 정수면 소수 없이 표시 (49.8%, 60%) [측정: s05, s01].
- 대지 면적이 0 이거나 비면 오류 "대지면적을 숫자로 입력해 주세요!" [측정: s04, s12]. 1층이 0이거나 빈칸이면 0%로 계산 [측정: s03, s11].
- 우리: 건폐율=건축면적/대지, 용적률=(연면적-지하면적)/대지, 한 자리 고정(60.0%) [측정: notes/건폐율용적률.md CalcFAR 설명, ours s01]. 대지와 건축면적이 모두 양수일 때만 결과를 낸다.

## 3. 상수·구간표
- 우리 화면의 용도지역별 법정한도표: 제1종전용 50/100, 제2종전용 50/150, 제1종일반 60/200, 제2종일반 60/250, 제3종일반 50/300, 준주거 70/500, 일반상업 80/1300, 준공업 70/400 (건폐율 %/용적률 %) [측정: ours s01 화면].
- 이 값은 국토의 계획 및 이용에 관한 법률 시행령 제84조제1항(건폐율)·제85조제1항(용적률)이 정한 각 용도지역의 상한과 같다. 다만 실제 한도는 그 범위에서 지자체 도시·군계획조례가 정한다 [측정: law.go.kr 원문, law/건폐율용적률.json]. 그쪽 화면에는 이 한도표가 없다 [측정: 응답 구조].

## 6. 판정과 불일치 예시
- 판정: 불일치 (비교 13건 중 11건 일치, 2건 불일치). 건물 면적이 0·빈칸이면 그쪽은 0%를 보이고 우리는 결과를 내지 않는다.
- 불일치 예시: 대지 100㎡, 1층 면적 0 -> 그쪽 건폐율 0%·용적률 0% vs 우리 결과 카드 없음 [측정: s03, s11]. 우리 코드는 건축면적이 양수일 때만 결과를 낸다 [측정: notes/건폐율용적률.md 의 CalcFAR 설명].
- 표시 자릿수 차이(그쪽 60% / 우리 60.0%)는 값이 같아 일치로 센다.

## 7. 못 찾음·미확인
- 그쪽이 건폐율에 1층만 쓰는지는 s10(1층 400, 상층 350)에서 40%로 나와 1층만 쓴다고 읽힌다 [측정: s10]. 지하층·옥상 구분은 그쪽 입력에 없어 연면적 지하 제외 기능의 대조는 못 함.
- 건폐율·용적률이 해당 용도지역의 한도를 넘는지 알려주는 기능은 양쪽 모두 결과 계산에는 쓰이지 않는다 [측정: s09 120%도 그냥 표시].
