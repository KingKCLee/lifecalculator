## 2. 계산식 정리
서버 계산이며 응답 비고의 식.
- 공실 및 미수손실 = 연간 총수익 × 공실률 — s02 [측정]
- 유효총수익 = 연간 총수익 − 공실손실 — s02 [측정]
- 순영업소득 = 유효총수익 − 운영경비 — s01 [측정]
- 수익가격 = 순영업소득 ÷ 환원율 — s01: 51,000,000÷0.045 = 1,133,333,333 [측정]
- 입력 검증: 공실률은 0 이상 100 미만, 운영경비는 연간 총수익보다 작아야 함, 환원율은 0보다 커야 함, 연간 총수익 0 불가 — s03, s05, s06, s09 [측정]
- 우리 식(CalcAppraisalMethods.jsx:63-65): 유효총수익 = 총수익×(1−공실률), 순영업소득 = 유효총수익 − 경비, 수익가액 = 환원이율>0 이면 NOI÷환원이율, 아니면 0 [측정: 코드 읽기]. 식은 같다.
