## 2. 계산식 정리
서버 계산이며 응답 비고의 식.
- 월임대료 환산액 = 월임대료 + 보증금 × 전환율 ÷ 12 — s02: 2,000,000 + 50,000,000×5%÷12 = 2,208,333 [측정]
- 보정 임대단가 = 환산액 ÷ 사례면적 × 시점% × 지역% × 개별% × 기타% (각각 ÷100). 화면 표시는 반올림(s01 35,714원)이나 시산값은 소수 그대로 곱한 값과 일치(s07 2,821,500) [측정]
- 사례 시산 월임대료 = 보정 임대단가 × 대상면적 — s05 [측정]
- 월 임대사례비교임료 = 시산 월임대료의 가중평균, 연 임료 = 월 × 12. s12 (3,000,000과 3,266,667의 1:1 평균) 3,133,333, s13 (3:1) 3,066,667, s14 (3건) 2,647,685 [측정]
- 입력 검증: 대상 면적 0, 사례 면적 0, 보증금·월임대료 모두 0 이면 거부 — s08~s10 [측정]
- 우리 식(CalcAppraisalMethods.jsx:26-28, 39): 단가 = 월임대료÷사례면적, 보정 k = 사정보정×(1+시점수정%÷100)×지역×개별, 비준임료(월) = 단가×k×대상면적, 연 환산 = ×12 [측정: 코드 읽기]. 보증금 환산만 빠졌고 나머지 구조는 같다.
