# 평수·면적 환산
- 그쪽 주소: https://부동산계산기.com/평수환산  · 계산 위치: 브라우저  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /평수변환계산기 (평 <-> ㎡ 만)  · 판정: 불일치

## 1. 입력 항목
- 6칸 동시 변환: 평(#pyung), ㎡(#msquare), ㎢(#kmsquare), sqft, acre, ha(#hectare). 아무 칸에나 쓰면 나머지가 채워진다(keyup). [측정: 표본 s01~s15 screen.values, notes/평수환산.md]
- 우리: 변환 방향 토글(㎡->평 / 평->㎡) 후 한 칸 입력. 결과 한 줄. ㎢·sqft·acre·ha 는 없다. [측정: ours 표본 화면]

## 2. 계산식 정리
- 그쪽: 1평 = 3.305785㎡ 를 상수로 쓰는 것으로 보인다. 표본 s07 에서 100,000㎡가 30250.001평(= 100000/3.305785)으로 나온다 [측정: s07; 추측: 상수 3.305785 사용].
- 표시 자릿수: ㎡ 3자리, 평 3자리, sqft 3자리, acre 3자리, ha 4자리, ㎢ 6자리. 입력한 칸은 입력값 그대로 둔다 [측정: s01, s04, s05 등].
- 우리: 평 = ㎡ x 121/400, ㎡ = 평 x 400/121 (정확한 분수), 표시는 소수 2자리 [측정: 화면 안내문 "1평 = 3.305785㎡ (정확히 400/121)", s07 30250.00].

## 3. 상수·구간표
- 1평 = 400/121 ㎡ = 3.30578512...㎡. 그쪽 상수 3.305785 는 이를 7자리에서 자른 값이다 [측정: 계산]. 법령에는 평의 환산계수를 정한 조문을 못 찾았다. 계량에 관한 법률 제4조(법정단위)·제6조제2항(비법정단위를 계량이나 광고에 쓰는 것을 제한)만 확인했다 [측정: law.go.kr 원문, law/평수환산.json].
- 다른 단위: 1 sqft = 0.09290304㎡ (s09 1000 sqft = 92.903㎡), 1 acre = 4046.856㎡ (s10), 1 ha = 10,000㎡ (s11) [측정].

## 6. 판정과 불일치 예시
- 판정: 불일치 (비교 11건 중 9건 일치, 2건 불일치). 일치는 우리 표시 자릿수(소수 2자리) 기준이며, 그쪽이 3자리를 보이는 경우 우리 값이 같은 참값의 올바른 반올림인지로 봤다.
- 불일치 예시: 평 0 입력 -> 그쪽 ㎡ 0.000 등 전부 0 표시 vs 우리 결과 카드 없음(입력 대기 화면). 평 -5 입력 -> 그쪽 -16.529㎡ vs 우리 결과 없음 [측정: s02, s14 화면]. 입력 해석(0·음수 허용 여부)의 기준 차이다.
- 상수 차이: 그쪽 3.305785 vs 우리 400/121. 큰 값에서 3자리 이상에서만 갈린다(s07 평 30250.001 vs 30250.00) [측정: s07].

## 7. 못 찾음·미확인
