# 지적측량수수료
- 그쪽 주소: https://부동산계산기.com/지적측량수수료  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /지적측량수수료계산기 (src/calcs/CalcSurveyFee.jsx)  · 판정: 불일치

## 1. 입력 항목
- 측량 종목 surveyType: 경계복원(boundary) / 분할(split) / 신규등록(newRegistration) / 등록전환(conversion) 등 8종 select [측정: rival-capture/html/지적측량수수료.html:785, 표본 s02, s11, s12, s15]
- 토지 구분 landRegisterType: 토지(land) / 임야(forest) / 수치(coordinate) [측정: 지적측량수수료.html:800, s09, s10]
- 지역 regionType: 군(county) / 시(city) / 구(district) [측정: 지적측량수수료.html:812, s12~s14]
- 개별공시지가 officialLandPrice 단위 원/㎡ [측정: 지적측량수수료.html:822]
- 면적 area(㎡), 필지수 parcelCount, 감면율 discountRate(%) [측정: 지적측량수수료.html:829, 838, 845]
- 신규등록·등록전환 종목은 공시지가를 비워 보내도 계산됐다 [측정: s12~s15 요청]

## 2. 계산식 정리
- 서버 계산이라 식은 응답의 항목과 값으로 추정한 것이다 [추측].
- 수수료 = 고시 기본단가 x 면적계수 x 필지수 (s10: 374,000 x 3필지 = 1,122,000) [측정: s10, s11]
- 감면액 = 수수료 x 감면율 (s10: 1,122,000 x 30% = 336,600). 공급가액 = 수수료 - 감면액 [측정: s10 응답]
- 부가세 = 공급가액 x 10%, 최종 = 공급가액 + 부가세 (s02: 305,000 + 30,500 = 335,500) [측정]
- 면적계수: 면적이 기준면적 이하이면 1, 초과하면 1보다 크다. 경계복원·토지 3,000㎡(기준 300㎡)에서 2.4 가 나왔다 [측정: s08]. 이 계수가 어떤 식으로 정해지는지는 표본 1개뿐이라 확정 못 함.
- 필지당 적용면적 = 대상면적 / 필지수 이고, 이 값으로 면적계수를 정하는 것으로 보인다 [추측: s10, s11 응답의 "필지당 적용면적" 항목]
- 고시 기본단가는 종목·토지구분·(공시지가 구간 또는 지역)로 정해진다 [측정: s02~s07, s12~s15]

## 3. 상수·구간표
- 경계복원·토지(도해)·군 지역의 공시지가 구간별 기본단가 [측정: s02~s07]:
  - 9,000원/㎡ 이하: 305,000원 (s02)
  - 9,001원 : 371,000원 (s03)
  - 51,000원 : 436,000원 (s04)
  - 51,001원 : 567,000원 (s05)
  - 1,710,000원 : 654,000원 (s06)
  - 17,060,000원 : 741,000원 (s07)
- 구간 경계가 정확히 어디서 끊기는지는 위 표본 쌍(9,000/9,001, 51,000/51,001)에서만 확인됐다. 2만6천원·17만원·853만원 근처는 표본이 없어 확정 못 함.
- 경계복원 기준면적: 토지 300㎡, 임야 3,000㎡ [측정: s02, s09 응답의 기준면적]. 분할·신규등록 등은 토지 1,500㎡ [측정: s11, s12]
- 신규등록측량·토지 기본단가: 군 436,000 / 시 614,000 / 구 688,000 [측정: s12~s14]. 등록전환·수치·시 지역 761,000 [측정: s15]
- 경계복원 임야 542,000 (공시지가 5만, s09), 경계복원 수치 374,000 (s10), 분할 토지 286,000 (s11) [측정]

## 6. 판정과 불일치 예시
- 판정: 불일치 (13/14). [측정: rival-capture/runs/지적측량수수료/ 와 ours-capture/runs/지적측량수수료/ 같은 id]
- 불일치 예시: 경계복원·토지·군, 공시지가 5만원/㎡, 면적 3,000㎡, 1필지 -> 그쪽 지적측량수수료 1,151,040원 vs 우리 479,600원 [측정: s08 양쪽 결과]. 우리 화면은 "면적 가산이 붙습니다" 안내문만 띄우고 금액에는 넣지 않는다 (src/calcs/CalcSurveyFee.jsx:43-47: 기준면적 초과 여부만 확인하고 수수료 계산식 줄 41 에는 면적이 들어가지 않는다) [측정: 코드 읽기].
- 같은 입력에서 그쪽 면적계수는 2.4 였다 [측정: s08]. 우리에는 면적계수가 없다.
- 나머지 단가표(공시지가 구간 7개 중 관찰된 6개, 지역별 단가, 임야·수치 단가), 필지수·감면율 처리, 부가세 처리는 관찰된 모든 표본에서 일치했다 [측정].
- s09(임야 3,000㎡)는 임야 기준면적이 3,000㎡라 면적 가산이 없어 일치했다 [측정: s09 그쪽 기준면적 3,000㎡].

## 7. 못 찾음·미확인
- s01(공시지가 0): 그쪽이 오류 응답을 줘서 비교에서 뺐다.
- 면적계수 산식은 표본이 s08 하나라서 못 찾음 (면적 3,000㎡, 기준 300㎡ -> 2.4 만 관찰).
- 공시지가 구간의 2만6천원·17만원·853만원 근처 경계는 표본이 없어 못 찾음.
- 그쪽 식은 서버 계산이라 코드를 볼 수 없다. 위 식은 [추측]이다.
