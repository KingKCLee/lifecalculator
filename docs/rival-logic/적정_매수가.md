# 적정 매수가
- 그쪽 주소: https://부동산계산기.com/매수가  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /적정매수가계산기 (src/calcs/CalcBuyPrice.jsx)  · 판정: 불일치

## 1. 입력 항목
- 목표 수익률 targetProfitRate(%) [측정: s01 요청]
- 예상 임차보증금 deposit, 예상 월차임 rent (단위 만원) [측정: 표본 요청 파라미터, specs/notes/매수가.md]
- 대출 포함 체크(loanYn) 후 대출금 loanAmt(만원)·이율 rate(%), 대출을 비용으로 계산 체크(excludeLoan) [측정: s10, s11]
- 운영비용 포함 체크(opexYn) 후 월 비용 mOpex(만원), 연 비용 yOpex(만원) [측정: s09]
- 목표 기간·목표 수익금액·매도 예상가격·기타 비용 칸은 요청에 같이 가지만 화면에서는 숨겨져 있다 [측정: specs/notes/매수가.md 가 인용한 html 752행 d-none, s01 요청 파라미터]

## 2. 계산식 정리
- 서버 계산이라 식은 응답 값으로 추정한 것이다 [추측].
- 연수익 = 월세 x 12 - 운영비용(월 비용 x 12 + 연 비용) - 대출 이자 [측정: s01 30,000,000; s09 25,800,000 = 30,000,000 - 1,200,000 - 3,000,000; s10 22,000,000 = 30,000,000 - 8,000,000]
- 적정 매수가 = 연수익 / 목표수익률 + 보증금 (+ 대출금). s01: 30,000,000 / 0.05 + 50,000,000 = 650,000,000 [측정: s01 값; 식은 문서 작성자 계산]
- 대출 포함(s10): 연수익 22,000,000 / 0.05 + 보증금 50,000,000 + 대출금 200,000,000 = 690,000,000이고 실 투자금액은 매수가 - 대출금 = 490,000,000 [측정: s10]
- 대출을 비용으로 계산(s11): 대출금은 더하지 않고 연수익 22,000,000 / 0.05 + 보증금 50,000,000 = 490,000,000 [측정: s11]
- 월세 0 이면 연수익 0 이라 적정 매수가는 보증금만 남는다 (s03 50,000,000) [측정]
- 목표수익률 0 은 오류 "목표수익률을 입력해 주세요!" [측정: s04]

## 3. 상수·구간표
- 상수·구간표는 없다 (순수 산술식).
- 목표수익률 4.5% 입력(s07)에서 적정 매수가 90,000,000 은 3,600,000 / 0.045 + 10,000,000 과 같다. 같은 응답의 "목표수익률" 표시 칸은 5%로 나왔다(소수 첫째 자리 반올림 표시로 보임) [측정: s07; 반올림 표시 판단은 [추측]].
- 안내 문구: 그쪽 설명 문구는 초기 투자비용(취득세 등)을 감안하지 않는다고 적고 있다 [측정: specs/notes/매수가.md 가 인용한 html intro 문구].

## 5. 우리 같은 입력 결과 및 대조
비교 항목은 "적정 매수가"(그쪽) 대 "최대 적정 매수가"(우리)이다. 우리는 월세 합계·보증금 합계·연간 경비·목표 수익률 칸에 같은 숫자를 넣었고 공실률·부대비용률·호가는 비웠다 [측정: specs/notes/매수가.md]. 우리 연간 경비 칸에는 운영비를 연 환산한 420만원(월 10 x 12 + 300)을 넣었다.

| s02 | 600,000,000 | 600,000,000 | 일치 |
| s03 | 50,000,000 | 계산 안 됨 (월세 입력 요구) | 불일치 |

| s08 | 11,000,000,000 | 11,000,000,000 | 일치 |
| s09 | 566,000,000 | 566,000,000 | 일치 |

## 6. 판정과 불일치 예시
- 판정: 불일치 (7/8). [측정: rival-capture/runs/매수가/ 와 ours-capture/runs/매수가/ 같은 id]
- 불일치 예시: 월세 0 · 보증금 5,000만원 · 목표수익률 5% -> 그쪽 적정 매수가 50,000,000원 vs 우리는 계산하지 않고 "월세 합계를 입력해주세요" 안내만 표시 [측정: s03 양쪽 결과]. 우리는 월세가 비어 있으면 필수 항목 누락으로 처리한다 (src/calcs/CalcBuyPrice.jsx:19 의 miss 규칙) [측정: 코드 읽기].
- 값이 있는 7개 표본에서 두 식은 같다: 우리 식은 (NOI / 목표 + 보증금) / (1 + 부대비용률) 이고 부대비용률을 비우면 그쪽 연수익 / 목표수익률 + 보증금과 같아진다 (CalcBuyPrice.jsx:5-6, 17-18) [측정: 표 대조].
- 구성 차이(비교 표 밖): 그쪽은 대출금·이율 입력과 "대출을 비용으로 계산" 옵션, 월/연 운영비 칸이 있다. 우리는 공실률·부대비용률·현재 호가(호가 기준 수익률 표시) 입력이 있고 대출 입력이 없다 [측정: specs/notes/매수가.md].

## 7. 못 찾음·미확인
- s04(목표수익률 0): 그쪽이 오류 응답을 줬고 우리도 입력 안내만 보여줘 둘 다 계산하지 않아 비교에서 뺐다.
- s10, s11(대출): 우리에 대출 입력이 없어 제외.
- 목표 기간·목표 수익금액·매도 예상가격 칸은 숨김이라 표본이 없어 못 찾음.
