# 예적금 이자
- 그쪽 주소: https://부동산계산기.com/예적금이자 (호출 /api/saving.php)  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /예적금이자계산기 (CalcDeposit, src/App.jsx:3323)  · 판정: 일치

## 1. 입력 항목
- 이자방식: 단리/복리 (요청값 interestType=simple|compound) [측정: s01, s02]
- 과세: 비과세/일반과세(15.4)/기타과세(세율 직접 입력) (요청값 taxType=none|basic|custom, taxRate) [측정: s05, s01, s06]
- 예금액(deposit, 만원), 월 적금액(saving, 만원), 기간(period, 개월 자유 숫자), 연이율(rate, %) [측정: rival-capture/html/예적금이자.html:782,793,806,817,828]
- 예금액과 월 적금액은 한 번에 같이 넣을 수 있다 [측정: s07]. 둘 다 비워도 되는지는 모름.
- 우리: 상품 유형 토글(예금 거치식/적금 적립식), 원금 또는 월 납입액 1칸(만원), 연이율, 기간 select(3·6·12·18·24·36개월), 세금 유형 3종(일반 15.4/세금우대 9.5/비과세) [측정: App.jsx:3323]. 단리만 있음.

## 2. 계산식 정리
입출력으로 추정한 식이다 [추측] (서버 계산이라 식 자체는 보이지 않음).
- 단리 예금: 세전이자 = 예금액 x 연이율 x 개월/12. 1억, 3.5%, 12개월 -> 3,500,000 [측정: s01]. 13개월 -> 3,791,667 [측정: s12]. 1억 x 0.035 x 13/12 = 3,791,666.7 의 반올림 값으로 보임 [추측].
- 단리 적금: 세전이자 = 월납입 x (연이율/12) x n(n+1)/2. 100만, 12개월 -> 227,500, 36개월 -> 1,942,500 [측정: s03, s13]. 회차표 1회차 이자 2,917 = 100만 x 0.035/12 [측정: s03]. 첫 달 분을 가입 때 넣는 것으로 본다는 안내문이 응답 basis 에 있음 [측정: s03].
- 예금+적금 동시: 두 이자를 더한 값 3,727,500 = 3,500,000 + 227,500 [측정: s07].
- 복리: 월복리로 보이는 값. 1억, 3.5%, 12개월 -> 3,556,695 [측정: s02]. 1억 x (1+0.035/12)^12 - 1억 과 같은 모양 [추측]. 120개월 41,834,482 [측정: s11].
- 이자소득세 = 세전이자 x 세율 (15.4%, 기타과세는 입력 세율), 세후 이자 = 세전이자 - 세금 [측정: s01 539,000 / 2,961,000, s06 332,500 / 3,167,500]. 세금 소수점은 원 단위 반올림으로 보임 (s12: 583,916.8 -> 583,917) [추측].
- 응답 특징: 비과세와 복리에서는 계산서에 이자소득세/세후 이자 줄이 나오지 않는다 [측정: s05, s02, s04, s11].
- 거부 사례: 연이율 0 이면 "연 이자율을 입력해 주세요!" 로 거부 [측정: s10].

## 3. 상수·구간표
- 일반과세 15.4%: 응답 비고에 "세전이자 x 일반과세 15.4%" [측정: s01]. 기타과세 세율은 입력값 [측정: s06 9.5%].
- 기간은 관찰 범위 3~120개월만 확인, 그 밖의 상한은 못 찾음 [측정: s08, s11].
- 법령 근거 대조는 불일치가 없어 수행하지 않음 (7번 참조).

## 5. 우리 같은 입력 결과 및 대조
우리 화면은 세후 수령액(원금 + 세후이자) 한 줄만 보여 주므로, 그쪽 값을 원금 + 세후이자로 환산해 비교했다 [측정: ours-capture/runs/예적금이자].
| 표본 | 그쪽(원금+세후이자) | 우리(세후 수령액) | 일치? |
|---|---|---|---|
| s01 | 100,000,000 + 2,961,000 = 102,961,000 | 102,961,000 | 일치 |
| s03 | 12,000,000 + 192,465 = 12,192,465 | 12,192,465 | 일치 |
| s05 | 100,000,000 + 3,500,000 = 103,500,000 | 103,500,000 | 일치 |
| s06 | 100,000,000 + 3,167,500 = 103,167,500 (우리는 세금우대 9.5% 버튼) | 103,167,500 | 일치 |
| s08 | 100,000,000 + 740,250 = 100,740,250 | 100,740,250 | 일치 |
| s09 | 100,000,000 + 8,883,000 = 108,883,000 | 108,883,000 | 일치 |
| s13 | 36,000,000 + 1,942,500 = 37,942,500 | 37,942,500 | 일치 |
비교 7건 중 7건 일치. 이자·세금을 따로 비교하지 못한 점은 한계다 (우리 화면 캡처 앞부분에서 세후 수령액만 읽음 [측정]).

## 6. 판정과 불일치 예시
- 판정: 일치 (비교 가능 7건 전부 같음) [측정]. 반올림 차이도 발견되지 않음.
- 우리 코드: 예금 이자 = 원금 x 연이율 x 개월/12, 적금 이자 = 월납입 x 연이율 x n(n+1)/24, 세금 = 반올림(이자 x 세율) [측정: src/App.jsx:3323]. 그쪽 추정식과 같은 모양.
- 불일치 예시: 없음.
- 범위 밖 차이(비교 불가, 기준차이): 우리에 복리, 예금+적금 동시 입력, 3~36개월 외 자유 기간(13개월·120개월), 기타과세 자유 세율이 없음 (s02, s04, s07, s11, s12).

## 7. 못 찾음·미확인
- s10 (금리 0%): 그쪽이 success=false 로 거부 -> 비교에서 제외 [측정].
- s02, s04, s07, s11, s12: 우리에 해당 기능 없어 비교 불가 [측정: specs/notes/예적금이자.md].
- 법령 대조(소득세법·조세특례제한법)는 불일치가 없어 수행하지 않음. 15.4% 가 소득세 14% + 지방소득세 1.4% 라는 설명은 두 사이트 화면 문구일 뿐이며 법령 원문으로 확인하지 않음.
- 그쪽 복리 식의 정확한 형태와 기간 상한은 못 찾음.
