# 감정평가수수료
- 그쪽 주소: https://부동산계산기.com/감정평가수수료  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /감정평가수수료계산기 (App.jsx CalcAppraisal)  · 판정: 불일치

## 1. 입력 항목
- 수수료 기준: 전체(all) / 하한액(low) / 기준액(standard) / 상한액(high), 요청 파라미터 commissionType [측정: rival-capture/html/감정평가수수료.html:809-823, 표본 s11~s13]
- 실비: 기본 실비(basic) / 실비 제외(no) / 직접입력(actual), 직접입력 시 expense(만원) [측정: 감정평가수수료.html:816-824, 표본 s14~s15]
- 예상평가액 amount, 단위 만원 — 요청에 입력 숫자가 그대로 가고 응답은 원 단위로 되돌려준다 [측정: 감정평가수수료.html:836, s02]
- 숨김값 dealType=sale, realEstate=house 가 같이 전송된다 [측정: 표본 요청 파라미터]

## 2. 계산식 정리
- 서버 계산이라 식은 응답의 비고 문구와 값으로 추정한 것이다 [추측].
- 기준 수수료 = 구간 기본액 + (구간 하한 초과분 x 요율). 하한 수수료는 초과분 항에 0.8, 상한 수수료는 초과분 항에 1.2를 곱하고, 구간 기본액도 하한은 646,000 / 상한은 844,000 처럼 따로 둔다 [측정: s04, s06 비고 문구와 값; 하한·상한 기본액 값은 s06 에서 관찰].
- 기본 실비 = 여비 40,000 + 공부발급비 5,000 + 기타 실비 20,000 = 65,000원 [측정: s02]
- 총액 = (수수료 + 실비) x 1.1 (VAT 10% 포함). s02: (250,000 + 65,000) x 1.1 = 346,500 [측정: s02 응답 총액 346,500, 곱셈은 문서 작성자가 계산]
- 실비 제외 선택 시 총액은 수수료 x 1.1 (s14 기준 총액 1,215,500 = 1,105,000 x 1.1), 직접입력 500만원이면 (수수료 + 5,000,000) x 1.1 [측정: s14, s15]

## 3. 상수·구간표
- 관찰된 기준 수수료 구간 [측정: s02~s10 비고 문구]:
  - 5천만 이하: 정액 250,000원
  - 5천만 ~ 5억: 25만원 + 5천만 초과액의 0.11%
  - 5억 ~ 10억: 745,000원 + 5억 초과액의 0.09%
  - 10억 ~ 50억: 1,195,000원 + 10억 초과액의 0.08%
  - 50억 ~ 100억: 4,395,000원 + 50억 초과액의 0.07%
  - 100억 ~ 500억: 7,895,000원 + 100억 초과액의 0.06% (150억 표본 s10 에서 관찰)
- 500억 초과 구간은 표본이 없어 확정 못 함.
- 정확히 5천만(s03)은 비고 문구가 "5천만원 ~ 5억원" 으로 나오지만 값은 250,000 으로 정액과 같다 [측정].

## 6. 판정과 불일치 예시
- 판정: 불일치 (일치 0 / 비교 9). [측정: rival-capture/runs/감정평가수수료/s02~s10.json 과 ours-capture/runs/감정평가수수료/ 같은 id]
- 불일치 예시: 예상평가액 5억(50000만원) -> 그쪽 기준 수수료 745,000원 vs 우리 기본 수수료 395,000원 (우리 VAT 포함 합계 434,500원, 그쪽 기준 총액은 실비 포함 891,000원) [측정: s06 양쪽 결과].
- 원인(우리 코드 읽기): 우리 구간식은 5천만 이하 20만원, 5천만~2억 20만 + 0.09%, 2~5억 15.5만 + 0.08%, 5~10억 39.5만 + 0.06%, 10~50억 69.5만 + 0.04% 이고 (src/App.jsx:3345) 그쪽 구간·요율(0.11%, 0.09%, 0.08%, 0.07%, 0.06%)과 기본액이 모두 다르다 [측정: 코드 줄과 s02~s10 값 대조].
- 우리 값이 구간 경계에서 줄어드는 지점: 우리는 100억 초과 구간의 기본액을 2,295,000(50억 구간 값)으로 두고 있어(App.jsx:3345) 100억 3,295,000 이 150억에서 2,795,000 으로 낮아진다 (s09 -> s10) [측정: 양 표본 결과, 원인 문장은 코드 읽기에 의한 추정 [추측]].
- 구성 차이(비교 표 밖): 그쪽은 하한·기준·상한 3종과 실비(여비·공부발급비·기타 실비 65,000원)를 더한 총액을 보여주고, 우리는 단일 값에 VAT 포함/별도 토글만 있다 [측정].

## 7. 못 찾음·미확인
- s01(평가액 0): 그쪽이 빈 결과를 줘서 비교에서 뺐다.
- s11~s15: 우리에 하한/상한 선택·실비 옵션이 없어 비교에서 뺐다.
- 500억 초과 구간의 그쪽 요율은 표본이 없어 못 찾음.
- 그쪽 식은 서버 계산이라 코드를 볼 수 없다. 위 식은 모두 [추측]이다.
