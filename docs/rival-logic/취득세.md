# 취득세
- 그쪽 주소: https://부동산계산기.com/취득세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /취득세계산기 (App.jsx CalcAcq)  · 판정: 불일치

## 1. 입력 항목
- 부동산 종류(realEstateType): 주택 / 오피스텔 등, 면적 구분(areaType=85 또는 big), 취득 방법(how=buy/free/inherit), 주택수(own=one/two/three) [측정: s01, s07, s08, s12, s13, s14 요청값]
- 취득가액(amount)·시가표준액(standardPrice) 만원 단위. 증여·상속은 취득가액란이 비고 시가표준액만 보낸다 [측정: s12, s13 요청값]
- 체크: 조정대상지역(conArea=Y), 법인(corporation=Y), 생애최초(firstOfLife=Y), 인구감소율(populationDeclineRate=25 기본 전송) [측정: 요청값]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 취득세 = 과세금액 x 취득세율, 지방교육세 = 과세금액 x 교육세율, 농특세 = 과세금액 x 0.2% (85㎡ 초과 주택, 오피스텔) [측정: s07, s14]
- 취득세 합계 = 취득세 + 지방교육세 + 농특세 - 생애최초 감면 후 값. 감면은 취득세 항목에서만 빼고 교육세는 감면 후 취득세의 10%로 다시 계산한 것으로 보인다 (s11: 감면 후 취득세 2,000,000, 교육세 200,000) [측정: s11 항목, 계산 방식은 추측]
- 6~9억 1주택 세율은 금액(억) x 2/3 - 3 (%) 로 이어지는 식을 쓰되 표시 세율은 소수 둘째 자리 이하에서 정리된 값으로 보인다 (s03: 6억 1만원인데 세율 1%, 취득세 6,000,100) [측정: s03, basis 문구 지방세법 제11조 1항 8호]

## 3. 상수·구간표
- 1주택 6억 이하 1%(s01, s02), 6억 초과~9억 비례(7.5억 2%, s04), 9억 3%(s05, s06) [측정]
- 2주택 조정대상 8%+교육세 0.4%(s08), 3주택 조정대상 12%(s09), 법인 12%(s10), 조정대상 3억 이상 증여 12%(s12) [측정]
- 상속 주택 0.8%, 교육세 0.16%(s13) [측정]. 오피스텔 매매 4%, 교육세 0.4%, 농특세 0.2%(s14) [측정]
- 생애최초 감면 한도 200만원(s11) [측정]. 인구감소 한도, 소득 요건 등은 확정 못 함.

## 6. 판정과 불일치 예시
- 판정: 불일치 (11/15) [측정: ours-capture/runs/취득세/s03, s11, s13, s14].
- 불일치 예시: 상속 주택 시가표준액 5억 -> 그쪽 4,800,000원(0.8%+교육세 0.16%) vs 우리 15,400,000원(2.8%+교육세 0.28%). 우리는 "상속 무주택특례" 체크가 있을 때만 0.8%를 쓰고 기본은 2.8%이다 (src/App.jsx:2032 근처 inheritNone). 그쪽은 같은 입력에서 기본으로 0.8%가 나왔다 [측정: s13 양쪽]. 입력 조건 차이 때문인지 그쪽 기본값인지는 못 가림 [추측].
- 그 외 원인: s11 감면은 우리가 취득세에서만 빼고 교육세는 4,000,000 기준 400,000 그대로 둬서(App.jsx:2055-2056 total=취득세+교육세+농특-감면) 2,400,000, 그쪽은 감면 후 취득세 기준 교육세 200,000 -> 2,200,000. s14는 그쪽이 오피스텔에 농특세 0.2%를 붙이는데 우리는 오피스텔은 농특세 없음 (App.jsx:2050 근처) 8,800,000 vs 9,200,000. s03은 우리가 6~9억 구간 세율을 소수점까지 이어 계산해(App.jsx:2014) 6,000,500, 그쪽은 1%로 표시되고 6,000,100 -> 400원 차이.

## 7. 못 찾음·미확인
- 그쪽 2주택 비조정, 비수도권, 농지, 인구감소 감면 표본은 없어 확인 못 함.
- s13 상속의 그쪽 0.8% 적용 조건(무주택 상속인 여부 입력)은 응답에서 못 찾음.
- 증여·상속의 과세표준을 시가표준액으로 쓰는지 취득가액과 비교하는지는 표본 s15가 두 값이 같아 확정 못 함.
