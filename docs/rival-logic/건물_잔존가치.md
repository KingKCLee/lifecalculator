# 건물 잔존가치
- 그쪽 주소: https://부동산계산기.com/잔존가치  · 계산 위치: 서버  · 측정일: 2026-10-15 [측정:라이브 부동산계산기.com]
- 우리 대응: /건물잔존가치계산기 (일부 대응: 구조·최종잔가율 개념 없음)  · 판정: 못찾음 (같은 입력으로 양쪽 결과가 모두 있는 표본 0건)

## 1. 입력 항목
- 건물 기준금액(만원), 준공연도(4자리), 기준연도(4자리), 건물 구조(선택). 선택하면 내용연수가 구조 그룹으로 정해진다. 직접입력(customYn) 모드에서는 내용연수(년)와 최종잔가율(%)을 직접 넣는다. 리모델링(remodelYn)과 리모델링 연도 입력도 있다. [측정: s01, s09 요청, notes/잔존가치.md]
- 우리 입력: 신축 가격(만원), 내용연수(20/30/40/50 선택), 경과연수(년), 감가 방법(정액법/정률법). 준공·기준연도 대신 경과연수를 직접 넣는다. [측정: ours-capture s09 화면 텍스트, App.jsx:3372 CalcBldValue]

## 2. 계산식 정리
서버 계산이다. 응답 "비고" 열의 식을 우리 말로 옮긴다 [측정: s01 비고 열].
- 경과연수 = 기준연도 - 준공연도.
- 연상각률 = 0.9 / 내용연수.
- 잔가율 = 1 - 경과연수 x 연상각률. 내용연수에 이르면 10% 에서 멈추고 초과하면 "최종잔가율 적용" 으로 10%. [측정: s03(50년 → 10%), s04(56년 → 10%)]
- 잔존가치 = 건물 기준금액 x 잔가율. 화면의 잔가율 표기는 정수 %("53%")이나 금액은 반올림 전 값으로 계산한다 (s01: 5억 x 0.532 = 266,000,000). [측정: s01, s05 162,500,000 = 5억 x 0.325]
- 우리 식: 정액법 잔존률 = 1 - 경과/내용연수 (0 이상 1 이하로 자름, 최종잔가율 없음). 정률법 잔존률 = 0.9 의 경과연수 제곱. [측정: App.jsx:3372]

## 3. 상수·구간표
- 구조 그룹과 내용연수: 철근콘크리트조 Ⅰ그룹 50년, 철골조 Ⅱ그룹 40년, 시멘트블록조 Ⅲ그룹 30년, 컨테이너건물 Ⅳ그룹 20년 [측정: s01, s05, s06, s07 응답]. 다른 구조의 그룹은 표본에서 관찰하지 않았다.
- 최종잔가율 10% (경계 s03, s04 에서 관찰). [측정]
- 위 4개 구조의 그룹 배정은 국세청 건물 기준시가 계산방법 고시(2026-39, 시행 2026-01-01) 제10조 제3항의 그룹별 구조 목록과 같다. 내용연수·최종잔존가치율 표 자체는 원문 텍스트에서 숫자가 추출되지 않아 대조하지 못했다. [측정: law.go.kr DRF admrul 일련번호 2100000271502 조회, 2026-10-15]

## 6. 판정과 불일치 예시
- 판정은 못찾음. 그쪽 결과가 있는 표본(s01~s07)은 구조 입력이 필요해 우리 쪽 표본을 만들지 못했고, 우리 표본(s09, s11~s14)은 그쪽 응답이 오류라 비교 가능한 쌍이 0건이다. [측정: 위 표]
- 참고(비교 표본 아님, 코드 읽기 추정): 그쪽 s01 과 같은 철근콘크리트조 5억·경과 26년을 우리에게 내용연수 50년 정액법으로 넣으면 1 - 26/50 = 0.48 이므로 240,000,000 이 되어 그쪽 266,000,000 과 달라질 것이다. 원인은 그쪽의 연상각률 0.9/내용연수 (최종잔가율 10%)와 우리 1/내용연수 (최종잔가율 0). 실행하지 않은 산술이므로 표본으로 세지 않는다. [추측: App.jsx:3372 와 s01 응답 식 비교]
- 불일치 예시: 해당 없음 (비교 가능 표본 0).

## 7. 못 찾음·미확인
- s09, s10, s11, s12, s13, s14 (직접입력): 요청은 전송됐으나 서버가 "건물 구조를 선택해주세요!" 로 거절해 계산 결과가 없다. 실행 상태는 ok 로 기록됐지만 응답은 success=false 이다. 직접입력 모드에서도 구조 선택이 필요한지는 모름 [추측: 구조 칸 미선택이 원인]. [측정: rival-capture/runs/잔존가치/s09~s14.json]
- s08 (실행 실패): 실패 사유 "locator.click: Timeout 16000ms exceeded." (3회+ 재시도 후 기록). 철근콘크리트조 1995 준공 + 리모델링 2015 표본. 그쪽 리모델링 반영식은 못 찾음. [측정: s08.json, progress.json failReason]
- 우리에 대응이 없는 것: 구조 그룹표, 최종잔가율, 리모델링 연도. 고시 제10조 내용연수·최종잔존가치율·신축연도별 잔가율 표의 숫자는 원문 텍스트로 열람하지 못했다.
- 못찾음 판정은 같은 입력으로 양쪽을 비교할 수 있는 성공 표본이 없다는 뜻이며 두 계산이 같다/다르다는 결론이 아니다 (R10).
