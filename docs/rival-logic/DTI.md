# DTI
- 그쪽 주소: https://부동산계산기.com/DTI  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /DTI계산기 (부분 대응: 원리금균등 신규대출만)  · 판정: 일치

## 1. 입력 항목
- 연소득·대출금액·기타부채액: 만원. 대출기간: 개월. 금리·기타부채금리·스트레스금리: %. [측정: notes/DTI.md 와 html/DTI.html 입력칸 라벨, s01 요청]
- 선택지: DTI / 스트레스 DTI(요청 dcd=dti|stress), 상환방식 만기일시(endAll)/원금균등(pSame)/원리금균등(iSame), 금리 직접입력 여부(rateInput Y/N), 기타부채 체크(deptYn). [측정: s01, s09, s10, s11, s12 요청]
- 우리 쪽 입력: 연 소득, 신규 대출금액(만원), 대출 금리(%), 대출 기간(5~40년 select), 기존 대출 월이자 합계(만원), 기존 대출 월 원금상환액(신DTI용). 상환방식 선택은 없고 원리금균등으로 고정. [측정: ours-capture 화면 텍스트, App.jsx:2968]

## 2. 계산식 정리
서버 계산이라 코드는 보이지 않는다. 응답 행에서 읽히는 식 [추측: 입출력으로 추정한 식].
- 월 상환액(원리금균등) = 원금 x r x (1+r)^n / ((1+r)^n - 1), r = 연금리/12, n = 개월. s01 의 3억, 4%, 360개월 값 1,432,246원이 이 식과 같다 [측정: s01 응답 / 추정식].
- 연 원리금 = 월 상환액 x 12 (s01 17,186,951원) [측정: s01].
- 기타부채 연이자 = 기타부채액 x 기타부채금리 (s08: 2.4억 x 5% = 12,000,000원) [측정: s08 응답 행].
- DTI = (연 원리금 + 기타부채 연이자) / 연소득 x 100, 소수 둘째 자리 표시 [측정: s01 34.37%, s08 58.37%].
- 만기일시(s09)는 연 원리금이 22,000,000원이며 대출 3억 x 4% = 12,000,000 와도 다르다. 식은 확정하지 못했다 [측정: s09 응답; 식은 모름].
- 원금균등(s10) 연 원리금 16,016,667원 [측정: s10], 스트레스 DTI(s11)는 금리를 5%로 올려(입력 4% + 스트레스 1%p) 원리금균등 계산 [측정: s11 비고 "스트레스금리 5%"].
- 화면 비고의 기타부채 이자 설명 문구는 "기간으로 나눠 12를 곱함" 식이지만 s08 값은 단순 금액 x 금리라 문구와 값이 맞지 않는다 [측정: s08 비고와 값].

## 3. 상수·구간표
- 스트레스 가산금리 기본값 1%p, 응답 비고에 "은행연합회 공시 금리" 라고 표기 [측정: s11].
- DTI 규제 구간(40/50/60%)은 그쪽 응답에 나오지 않는다. 우리 화면은 투기과열 40%, 조정 50%, 비규제 60% 판정을 따로 보여준다. [측정: 우리 s03 화면 텍스트]
