# 지역자원시설세
- 그쪽 주소: https://부동산계산기.com/지역자원시설세  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /지역자원시설세계산기 (src/calcs/CalcResourceTax.jsx)  · 판정: 불일치

## 1. 입력 항목
- 건물 종류(realEstateType): 주택(house) / 그 외(other) [측정: s01, s11 요청값]
- 건물시가표준액(buildingStandardPrice), 만원 단위 (입력칸 안내문 "만원 단위 금액") [측정: specs/notes/지역자원시설세.md]
- 체크: 화재위험건축물(fireHazard), 대형 화재위험건축물(bigFireHazard), 주택일 때 1세대1주택(oneHouse) [측정: s13, s14, s15 요청값]

## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식이다 [추측].
- 과세표준 = 건물시가표준액 x 비율. 그 외 건축물 70%(s01: 600만 -> 420만), 주택 60%(s11: 1,000만 -> 600만), 1세대1주택 43%(s15: 1억 -> 4,300만) [측정]
- 세액 = 과세표준에 6단계 누진세율(0.04%~0.12%)을 적용한 값 [추측: s03 9,100,000 -> 2,400+(9,100,000-6,000,000) x 0.05% = 3,950, 응답 3,950과 일치]
- 화재위험은 세액 x 2배, 대형은 x 3배로 중과 [측정: s13 중과세율 0.12 / s14 0.18, 세액 21,400 / 32,100]
- 우리와 달리 10원 단위 내림이 없다 (s02 1,683원, s04 3,954원 같은 1원 단위 값) [측정]

## 3. 상수·구간표
- 세율 열(응답 "세율"): 과표 약 420만(600만 구간 이하) 0.04, 910만 0.05, 1,820만 0.06, 2,730만 0.08, 4,480만~6,000만 0.1 [측정: s01, s03, s05, s07, s09, s12]
- 구간 기준액은 과세표준 6백만/1천3백만/2천6백만/3천9백만/6천4백만 원으로 보인다. 같은 누진표가 우리 코드에도 있다 (CalcResourceTax.jsx 6행) [측정: 응답 수치와 식의 일치 / 구간 경계 자체는 표본 부족으로 확정 못 함]
- 화재위험 중과: 일반 6% 구간 3,000만 -> 과표 2,100만, 2배 21,400, 3배 32,100 [측정: s13, s14]

## 6. 판정과 불일치 예시
- 판정: 불일치 (2/14). [측정: ours-capture/runs/지역자원시설세/s01~s14]
- 불일치 예시: 일반 건축물 건물시가표준액 600만원 -> 그쪽 지역자원시설세 1,680원 vs 우리 2,400원.
- 원인 1(비율): 우리는 일반 건축물의 과세표준을 시가표준액 전액으로 둔다 (src/calcs/CalcResourceTax.jsx:15, base = 주택이면 60%, 아니면 100%). 그쪽은 그 외 건축물에도 70%를 곱한다 (s01 과표 4,200,000) [측정: s01]. 주택(60%)은 두 쪽이 같아 s11, s12만 일치한다.
- 원인 2(10원 내림): 우리는 최종 세액을 10원 단위로 내린다 (CalcResourceTax.jsx:16). 그쪽은 내림이 없어 s02 1,683 같은 값이 나온다 (반올림 차이 성격) [측정: s02].
- 원인 3(중과): 위 70% 차이가 2배·3배 중과 표본에도 그대로 곱해져 s13 21,400 vs 33,800, s14 32,100 vs 50,700으로 벌어진다 [측정].
- 우리에 없는 것: 1세대1주택 특례(s15) [측정: specs/notes/지역자원시설세.md].

## 7. 못 찾음·미확인
- s15(1세대1주택)는 우리에 해당 입력이 없어 비교에서 뺐다.
- 그쪽 "그 외 건축물 70%"의 법령 근거는 응답 basis로 확인하지 못했다.
- 과표 6,400만 초과 구간의 세율과 지자체 조례 가감 처리는 표본이 없어 못 찾음.
