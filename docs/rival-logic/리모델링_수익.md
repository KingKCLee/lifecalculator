## 1. 입력 항목

## 2. 계산식 정리
서버 계산이라 코드는 안 보이고, 응답 수치를 재계산해 맞는 식은 아래와 같다 [추측: 입출력으로 추정한 식, 전 표본 수치 일치 확인은 s01~s13 손계산].
- 공사면적 = 대지면적 × 용적률 × 2.18 (예: 50,000×2.00×2.18 = 218,000) [측정: s01 응답과 일치].
- 총 사업비 = 공사면적 ÷ 3.305785 × 평당 사업비 (s01 428,642,516,074원) [추측].
- 증가 세대수 = 현재 세대수 × 증가율, 소수점 버림 (s13: 1세대×15% → 0세대) [측정: s13 응답].
- 목표 분양가 = 신축 시세 × 0.8 × (신축 평수 ÷ 현재 평수); 분양가를 직접 넣으면 그 값 (s01 1,088,000,000원, s09 1,000,000,000원) [추측].
- 분양 수익 = 증가 세대수 × 목표 분양가 [측정: s01 150×1,088,000,000 = 163,200,000,000].
- 세대별 분담금 = (총 사업비 - 분양 수익) ÷ 현재 세대수 [추측; s01, s02 수치 일치].
- 증가된 평수 = 현재 평수 × (1 + 면적 증가율) (s01 39평) [측정].
- 목표 시세 = 신축 시세 ÷ 신축 평수 × 증가된 평수 (s01 1,376,470,588원) [추측].
- 시세 차익 = 목표 시세 - 현재 시세; 실제 수익 = 시세 차익 - 세대별 분담금 [측정: s01 576,470,588-265,442,516 = 311,028,072].

## 3. 상수·구간표
- 공사면적 계수 2.18, 평 환산 3.305785(≈0.3025 평/㎡), 분양가 추산 비율 80% [추측: 표본 역산].
- 안내문의 세대수 15% 상한은 서버에서 거절되지 않음: 16%(s04)도 160세대로 계산, 면적 50%(s05)도 45평으로 계산 [측정: s04, s05 응답].
