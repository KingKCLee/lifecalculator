# 최저가·입찰보증금
- 그쪽 주소: https://부동산계산기.com/유찰가  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /경매최저가계산기 (src/calcs/CalcMinBid.jsx)  · 판정: 불일치

## 1. 입력 항목
- 감정가(appraisalValue, 만원), 유찰횟수(failCount, 자유 숫자, 화면 기본 3), 저감률 방식(reductionMode: 20 / 30 / mixed_30_20 / custom), 직접 저감률(customReductionRate, %), 입찰보증금율(depositRateType: 10 / 20 / custom), 직접 보증금율(customDepositRate, %) [측정: rival-capture/html/유찰가.html:784-822, s01~s08 요청값].
- 우리: 감정가(만원), 저감률 버튼 20%/30%, 유찰 횟수 select 0~5회, 보증금 버튼 10%/20%/30% [측정: CalcMinBid.jsx:15-22].

## 2. 계산식 정리
서버 계산이라 식은 추정이다 [추측].
- 회차 i 의 최저매각가격 = 감정가 x (1 - 저감률)^i, 정확값 기준으로 보인다 [측정: s10 123,450,000 x 0.7^4 = 29,640,345 와 응답 일치; s12 100억 x 0.7^5 = 1,680,700,000 와 응답 일치].
- 입찰보증금 = 해당 회차 최저가 x 보증금율, 원 미만은 버림으로 보임 [측정: s10 4회 29,640,345 x 10% = 2,964,034.5 -> 2,964,034; s13 10회 5,368,709].
- 혼합(1회 30%, 이후 20%): 1회 70%, 2회 56% [측정: s05]. 직접 저감률 25%: 75%, 56.25%, 42.19% [측정: s06].
- 유찰 0회는 신건 한 줄만 표시, 혼합 모드여도 영향 없음 [측정: s02, s14].
- 우리 식: 최저가 = 내림(감정가 x (1-r)^회차) 을 0~5회 6줄 표로 [측정: CalcMinBid.jsx:13], 보증금 = 최저가 x 비율 [측정: CalcMinBid.jsx:16-17,24].

## 3. 상수·구간표
- 저감률 20%, 30%, 혼합(1회 30% 후 20%), 임의 비율 [측정: s01, s03, s05, s06].
- 보증금율 10% (일반 매각 기준), 20% (재매각 기준), 직접입력 30% [측정: 응답 비고, s01, s07, s08].
- 유찰횟수: 10회까지 계산됨, 그 이상은 못 찾음 [측정: s13].

## 6. 판정과 불일치 예시
- 판정: 불일치 (2건, 모두 1원).
- 원인: 우리 코드가 부동소수 거듭제곱에 내림을 적용한다 (src/calcs/CalcMinBid.jsx:13). 0.7의 4제곱이 정확값 0.2401 보다 작게 계산되어 내림하면 1원이 빠진다 [측정: node 에서 Math.floor(123450000*Math.pow(0.7,4)) = 29640344, 정수 계산 123450000*2401/10000 = 29640345]. 수정은 하지 않음.
- 불일치 예시: 감정가 1억2345만원, 30% 저감, 4회 유찰 -> 그쪽 29,640,345원 vs 우리 29,640,344원 (1원 차이, 반올림·절사 차이) [측정: s10].
- 표기 차이(값은 같음): 감정가 대비 비율을 그쪽은 소수 2자리(32.77%, 24.01%), 우리는 소수 1자리(32.8%, 24.0%)로 보여 준다 [측정: s04, s10, s12].
- 비교 불가(기준차이): 혼합 저감, 직접 저감률, 유찰 6회 이상, 임의 보증금율은 우리에 없음 (s05, s06, s13, s14).

## 7. 못 찾음·미확인
- s11 (감정가 0): 그쪽 success=false 거부 -> 비교 제외. 우리는 안내 문구와 0원 표시 [측정].
- s05, s06, s13, s14: 우리에 해당 옵션이 없어 비교 불가.
- 1원 끝수를 어떻게 처리해야 하는지는 법령에서 못 찾음 (law/유찰가.json 참조).
