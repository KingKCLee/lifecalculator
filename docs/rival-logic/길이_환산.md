# 길이 환산
- 그쪽 주소: https://부동산계산기.com/길이  · 계산 위치: 브라우저  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /길이환산계산기  · 판정: 일치

## 1. 입력 항목
- 그쪽 5칸 동시 변환: 미터(m), 인치(in), 피트(ft), 야드(yd), 마일(mi). 피트+인치 표시칸(ft_inch)은 읽기 전용. [측정: 표본 screen.values]
- 우리: 단위 select 와 값 1칸. 결과로 미터·cm·mm·km·in·ft·yd·mi·자(尺)·간(間)을 한꺼번에 보인다. [측정: ours 표본 화면 s01]

## 2. 계산식 정리
- 그쪽: 1in = 0.0254m, 1ft = 0.3048m, 1yd = 0.9144m, 1mi = 1609.344m 로 환산. 표본값이 정확히 이 비율이다(s04 0.3048m = 12.000in = 1.000ft, s09 1mi = 63360in = 5280ft = 1760yd) [측정: s04, s09, s10].
- 표시 자릿수: m·in·ft·yd 3자리, mi 5자리, 입력한 칸은 그대로 [측정: s01, s11].
- 우리: 같은 비율로 환산하되 표시는 최대 6자리 유효, 1e6 이상·1e-4 미만은 지수 표기 [측정: ours s11 "1.0000e+6 m", s12, notes/길이.md]. 자(尺)는 1m=3.3자, 간(間)은 1m=0.55간(= 6자)로 환산한다 [측정: ours s01 화면 3.3, 0.55].

## 3. 상수·구간표
- 국제 야드·파운드 협정의 정의값(in/ft/yd/mi)이다. 한국 계량에 관한 법률·시행령·시행규칙에는 인치·피트·야드·마일의 환산값 조문이 없었다 [측정: law.go.kr 조회, law/길이.json].

## 6. 판정과 불일치 예시
- 판정: 일치 (15건 모두 일치). 숫자 자체는 모두 같은 참값이며 차이는 표기뿐이다: 큰 값은 우리가 지수 표기(s11, s15 의 m 칸 1.2346e+6), 작은 값은 그쪽이 0.000 으로 잘라 보여준다(s12).
- 불일치 예시는 없음. 표기 차이 예시: 미터 1,000,000 입력 -> 그쪽 인치 39370078.740 vs 우리 3.9370e+7 [측정: s11].
- 그쪽만 있는 기능: 피트+인치 표시칸. 우리만 있는 기능: cm·mm·km·자·간 [측정].

## 7. 못 찾음·미확인
- 한국 법령에서 인치·피트·야드·마일 환산 정의 조문은 못 찾음 (계량에 관한 법률 시행령·시행규칙 본문 검색 결과 없음) [측정: law.go.kr 조회 2026-10-15].
- 자(尺)=10/33 m, 간=6자 환산은 우리 쪽 값만 있고 그쪽에는 없어 대조하지 못했다.
