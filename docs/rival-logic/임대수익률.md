# 임대수익률
- 그쪽 주소: https://부동산계산기.com/임대수익률  · 계산 위치: 서버  · 측정일: 2026-10-15 [측정:라이브 부동산계산기.com]
- 우리 대응: /임대수익률계산기 (일부 대응: 월세·보증금·월 경비·대출만 겹침)  · 판정: 불일치 (성공 표본 범위에서만, R10)

## 1. 입력 항목
- 가격류는 전부 만원: 매매가(price), 보증금(deposit), 월세(rent), 기타 연수익(etcProfit), 1회성 기타비용(etcCost), 월 비용(mOpex), 연 비용(yOpex), 대출금(loanAmt). 이율(rate)만 %. [측정: s01 요청, notes/임대수익률.md 의 html 895~1019행 단위 확인]
- 선택 항목: 용도(realEstateType)·지역(regionType)·면적(areaType)·주택수(own), 대출 포함(loanYn), 운영비용 포함(opexYn). 체크 전에는 대출·운영비 칸이 숨어 있다. [측정: s05, s07 요청]
- 우리 입력: 매입가, 보증금, 월세, 월 관리비·경비, 대출금액, 대출 금리 (모두 만원/%). 연 비용·기타 수익·1회성 비용 칸은 없다. [측정: ours-capture s01 화면 텍스트, notes/임대수익률.md]

## 2. 계산식 정리
서버 계산이라 코드는 보이지 않는다. 아래는 응답 행의 "비고" 열에 적힌 식을 우리 말로 옮긴 것이다 [측정: 응답 비고 열].
- 투자금 = 매매가 - 보증금. 대출 포함이면 매매가 - (대출금 + 보증금). [측정: s01, s05]
- 월이자 = 대출금 x 이율 / 12. 월수익 = 월세 - 월이자 (- 월비용). 연수익 = 월수익 x 12. [측정: s05, s08]
- 대출이 없고 운영비용도 월 단위가 아니면 연수익 = 월세 x 12. 연 비용을 넣으면 연수익 = 월세 x 12 - 연 비용, 기타 연수익을 넣으면 월세 x 12 + 기타 연수익. [측정: s01, s12, s13]
- 연수익률 = 연수익 / 투자금 x 100. 정수면 "3%", 아니면 소수 둘째 자리까지 "4.63%" 로 표시. [측정: s01, s10]
- 투자금이 0 이하이면 수익률을 100% 로 두고 그 사실을 근거 칸에 적는다. [측정: s03, s06 basis 문구 "투자 금액이 0원 이하이므로, 수익률이 100%로 계산되었습니다"]
- 우리 식: 연 임대수입 = 월세 x 12, 연 경비 = 월경비 x 12, 연 이자 = 대출 x 금리, 순수익 = 수입 - 경비 - 이자, 자기자본 = 매입가 - 보증금 - 대출, 순수익률 = 자기자본이 0 초과일 때만 순수익/자기자본 x 100, 아니면 0. [측정: App.jsx:3234 CalcYield]
- 1회성 비용을 넣으면 그쪽은 부대비용 회수 기간·부대비용 감안 수익률·투자금 회수 기간을 추가로 낸다. 식은 응답 근거 문단에 일부만 나오고 확정하지 못했다. [측정: s14]

## 3. 상수·구간표
- 세율·구간표는 없다. 월 환산은 12개월 고정. [측정: s01, s05]
- 투자금 0 이하일 때 100% 표기는 그쪽 고정 규칙으로 보인다. [추측: s03, s06 두 표본에서만 관찰]
- 운영비 월 20만원이면 연 240만원(월 x 12). [측정: s07]

## 6. 판정과 불일치 예시
- 비교한 12표본 중 9표본이 연수익과 수익률 모두 원 단위·소수 둘째 자리까지 같고 3표본이 다르다. 판정은 불일치. 일치한 9표본은 월세·보증금·월 경비·대출금·금리 입력 범위에 한정된다 (R10). [측정: 위 표]
- 원인 1 (s03, s06): 투자금(자기자본)이 0 이하일 때 그쪽은 수익률 100% 로 표시하고, 우리는 자기자본 0 이하면 순수익률을 0 으로 둔다. [측정: s03·s06 응답 basis, 우리 s03·s06 화면 / 코드 근거: App.jsx:3234 의 inv>0 분기]
- 원인 2 (s10): 정확한 값은 185,000,000 / 4,000,000,000 x 100 = 4.625 이다. 그쪽은 4.63, 우리 화면은 4.62. 반올림 차이. [측정: s10 양쪽 값, 산술]
- 불일치 예시: 매매가 5억·보증금 5억·월세 50만원 → 그쪽 연수익률 100% vs 우리 순수익률 0.00% (자기자본수익률은 N/A). [측정: s03]
- 그쪽 s06 근거 문단은 대출금을 투자금에서 빼지 않고 비용으로 계산할 수도 있다고 안내한다. 즉 투자금 0 처리는 그쪽도 예외 처리임을 인정하는 문구다. [측정: s06 basis]

## 7. 못 찾음·미확인
- s15 (실행 실패): 실패 사유 "locator.click: Timeout 32000ms exceeded." (3회+ 재시도 후 기록). 내용은 주택 버튼 + 취득세·중개보수·국민주택채권 자동계산 체크 표본이다. 비교에서 뺐고 그쪽 결과는 못 얻었다. [측정: rival-capture/runs/임대수익률/s15.json, progress.json failReason]
- s13(기타 연수익), s14(1회성 기타비용)는 그쪽 응답이 있으나 우리에 해당 입력 칸이 없어 비교하지 않았다 (실행 실패 아님). 따라서 그쪽의 부대비용 회수 기간·감안 수익률 식은 우리와 대조하지 못했다. [측정: notes/임대수익률.md]
- 투자금 0 이하일 때 100% 표기가 모든 입력에서 같은지, 그리고 취득세 등 부대비용이 투자금에 들어가는지는 모름 (취득세 자동계산 표본 s15 실패).
- 일치 판정은 위 12표본(성공 표본) 범위에서만 성립하고 s15 영역은 미확인이다.
