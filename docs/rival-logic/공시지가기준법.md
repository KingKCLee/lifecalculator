## 1. 입력 항목
- 표준지공시지가 · 원/㎡ (다른 감정평가 계산기와 달리 만원이 아님) — 근거: 표본 s01 요청 standardPrice=3500000 과 응답 "(원/㎡)", specs/rival/공시지가기준법.json [측정]

- 시점수정·지역요인·개별요인·그 밖의 요인 · % (100=보정 없음) — 표본 요청 timeFactor, regionFactor, individualFactor, otherFactor [측정]
- 우리 쪽 입력: 비교표준지 공시지가(원/㎡), 시점수정(지가변동률 누계 %), 지역요인·개별요인·그 밖의 요인(배수), 대상 토지 면적 — 근거: CalcAppraisalMethods.jsx:46-56 [측정]

## 2. 계산식 정리
- 기초가액 = 표준지공시지가 × 면적 — 응답 비고, s01 [측정]
- 토지가액 = 기초가액 × 시점% × 지역% × 개별% × 기타% (각각 ÷100) — 응답 비고 "기초가액 × 각 보정률", s02~s06 [측정]. s06 에서 3,500,000×330×1.018×1.05×0.90×0.975 = 1,083,343,511 로 맞음 [측정: 계산은 작성자]
- 입력 검증: 면적 0, 공시지가 0, 보정률 0 이하이면 거부 — s07, s08, s11 [측정]
- 우리 식(CalcAppraisalMethods.jsx:47-48): ㎡당 단가 = 공시지가 × (1+시점수정%÷100) × 지역 × 개별 × 기타, 토지가액 = 단가 × 면적 [측정: 코드 읽기]. 곱셈 구조가 같다.
- 두 계산기 모두 비교표준지를 고르는 단계와 지가변동률 조회는 하지 않고 사용자가 보정률을 직접 입력함 [측정: 입력 항목 기준].
