# 전세 vs 월세 비교
- 그쪽 주소: https://부동산계산기.com/전월세비교  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /전세월세비교계산기 (src/calcs/CalcJeonseWolse.jsx)  · 판정: 불일치

## 1. 입력 항목
- 고급 계산 여부 advancedYn(기본 N), 공통 기대수익률 commonOwnReturnRate(기본 3%), 공통 대출이율 commonLoanRate(기본 4%) [측정: rival-capture/html/전월세비교.html:784-800, 표본 요청 파라미터]
- 전세: 내 자금 leaseOwnFund, 대출금 leaseLoan (단위 만원) [측정: s01, s02]
- 월세: 보증금 중 내 자금 rentOwnFund, 보증금 중 대출 rentLoan, 월세 rentMonthlyRent (단위 만원) [측정: s01, s12]
- 비교 기간 compareMonths(숨김값 24), 일회성 비용·월 추가비용 칸(고급 모드용, 이번 표본 미사용) [측정: 요청 파라미터]
- 전세 쪽만 입력하면 전세 월비용만 표시되고 판정은 나오지 않는다 [측정: s11]

## 2. 계산식 정리
- 서버 계산이라 식은 응답 값으로 추정한 것이다 [추측]. 결과 단위는 "월" 비용이다 [측정: specs/notes/전월세비교.md 가 인용한 html 760행 설명, 응답 값 크기].
- 전세 내 자금 기회비용(월) = 내 자금 x 기대수익률 / 12. 예: 1억 x 3% / 12 = 250,000 [측정: s01 값 250,000, 계산은 문서 작성자]
- 전세 대출 이자(월) = 대출금 x 대출이율 / 12. 예: 2억 x 4% / 12 = 666,667 [측정: s01 값]
- 월세 월비용 합계 = 월세 + 월세 보증금 기회비용 + 월세 보증금 대출 이자 [측정: s12 합계 1,091,667 = 1,000,000 + 25,000 + 66,667]
- 판정: 전세 월비용 합계와 월세 월비용 합계 비교 — 전세가 작으면 "전세 유리", 월세가 작으면 "월세 유리", 같으면 "동일" [측정: s03 동일, s04 월세 유리, s05 전세 유리]
- 공통 이율을 바꾸면 전세·월세 양쪽에 같이 적용된다 (s07: 10%/10% 에서 월세 보증금 기회비용 250,000 = 3000만 x 10% / 12) [측정]

## 3. 상수·구간표
- 기본 공통 이율: 기대수익률 3%, 대출이율 4% [측정: s01 요청 파라미터]
- 비교 기간 24개월이 숨김값으로 같이 전송되지만 응답 금액은 월 단위라 곱해지지 않았다 [측정: s01 요청과 응답]
- 판정 경계: 월세 67.5만원 동일, 67만원 월세 유리, 68만원 전세 유리 (전세 3억 무대출, 예금 3%, 월세 보증금 3000만) [측정: s03~s05]
- 월세만 있고 월세 보증금이 있는데 월세 0 이면 오류 "월세 보증금을 입력한 경우 월세 금액도 함께 입력해주세요." [측정: s13]

## 5. 우리 같은 입력 결과 및 대조
그쪽 결과는 월 단위(원), 우리 화면은 연간 부담(원)이다 [측정: specs/notes/전월세비교.md, 우리 화면 "전세 연간 부담"]. 비교는 우리 연간 값을 12로 나눠 원 단위로 반올림한 월 값을 그쪽 월비용 합계와 대조했다(나눗셈은 문서 작성자가 계산). 판정(유리한 쪽)도 같이 대조했다.
| 표본 | 그쪽 | 우리 | 일치? |
|---|---|---|---|

| s02 | 750,000 / 1,075,000 / 전세 유리 | 9,000,000/12=750,000 / 1,075,000 / 전세 | 일치 |

## 6. 판정과 불일치 예시
- 판정: 불일치 (9/10). [측정: rival-capture/runs/전월세비교/ 와 ours-capture/runs/전월세비교/ 같은 id]
- 불일치 예시: 전세 3억(무대출), 월세 보증금 3000만 + 월세 67.5만원, 예금 3% -> 그쪽 전세 750,000원 vs 월세 750,000원, 판정 "동일" / 우리는 월세 칸에 67.5 를 넣으면 값이 들어가지 않아 "월세를 입력해주세요" 가 뜨고 결과 비교가 안 된다 [측정: s03 우리 화면]. 정확히 같은 비용이 되는 경계 입력이 우리에서는 재현되지 않는다.
- 일치한 9개 표본은 월세 소수점이 없는 입력이다. 우리 식은 전세 = 대출 x 대출금리 + 자기자금 x 예금금리, 월세 = 월세 x 12 + 월세 보증금 x 예금금리 로 (src/calcs/CalcJeonseWolse.jsx:17-18) 그쪽 월 식에 12를 곱한 것과 값이 같다 [측정: 위 표 대조].
- 구성 차이(비교 표 밖): 그쪽은 월세 보증금 중 대출·일회성 비용·월 추가비용 입력(고급 모드), 우리는 월세 보증금 대출·일회성 비용 입력이 없고 거주 기간(년)과 손익분기 전환율을 보여준다 [측정: specs/notes/전월세비교.md, 우리 화면].
- 월 환산에서 1원 안팎 차이는 나눗셈 반올림 때문에 생긴 것이고 표본 9개에서는 모두 원 단위로 같았다 [측정: 위 표].

## 7. 못 찾음·미확인
- s11(전세 쪽만 입력): 우리는 월세가 필수라 비교 불가. 제외.
- s12(월세 보증금 대출 포함): 우리에 입력이 없어 제외.
- s13(월세 0): 양쪽 모두 입력 오류로 계산하지 않아 제외.
- 고급 모드(일회성 비용·월 추가비용)는 표본이 없어 못 찾음.
- 그쪽 식은 서버 계산이라 코드를 볼 수 없다. 위 식은 [추측]이다.
