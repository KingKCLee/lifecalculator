# 상속세
- 그쪽 주소: https://부동산계산기.com/상속세  · 계산 위치: 서버 (/api/inherit.php)  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /상속세계산기  · 판정: 불일치

## 1. 입력 항목
- 상속재산가액(amount, 만원), 배우자 유/무(spouse=Y/N), 인적공제 계산 모드(humanDeductYn)와 자녀·존속 등 인원수, 채무(dept), 장례비용 등(cost), 순금융상속액(financialInheritAmt), 동거주택(cohabitAmt), 과거 증여(pastAmt) 등. [측정: s01~s15 요청 본문]
- 자녀공제 기본값 5000, 일괄공제 기본값 50000(만원)이 요청에 함께 실려 나간다. [측정: s01 요청]
- 우리 쪽은 총 상속재산·금융재산·채무·장례비·10년 내 사전증여·배우자 유무·자녀 수(select, 기본 2명)·동거주택·영농상속·6개월 내 신고(3%) 토글. [측정: specs/notes/상속세.md, ours s01 화면]

## 2. 계산식 정리
서버 계산이므로 아래는 입출력으로 추정한 식이다 [추측]. 근거는 표본 id.
- 과세가액 = 상속재산 + 사전증여 − 채무 − 장례비용(입력값을 그대로 반영). [측정: s10, s11, s14 응답 비고]
- 공제 = 일괄공제 5억(기초 2억+인적공제보다 크면 적용, 응답 basis 문구) + 배우자 있으면 배우자 공제 5억 고정 + 금융재산·동거주택 공제. [측정: s01, s09, s12, s13] 배우자 공제를 법정상속분으로 늘리는 동작은 표본에서 보이지 않았다(s09에서 20억 상속에도 5억). [측정: s09]
- 과세표준 = 과세가액 − 공제 합계, 누진세율 적용 후 3% 신고세액공제. [측정: s02, s05]

## 3. 상수·구간표
- 세율: 1억 이하 10%, 5억 이하 20%(누진공제 1천만), 10억 이하 30%(6천만), 30억 이하 40%(1.6억), 30억 초과 50%(4.6억). [측정: s02~s08 응답 비고]
- 일괄공제 5억, 배우자 기본공제 5억, 신고세액공제 3%. [측정: s01, s02]
- 금융재산 공제: 순금융 2억 입력 시 4천만(20%) 관측. 2천만·1억 이하 구간의 값은 관측하지 못했다. [측정: s12 / 나머지 구간 못 찾음]
- 동거주택 공제: 3억 입력 시 3억(최대 6억 안내 문구). [측정: s13]

## 6. 판정과 불일치 예시
- 판정: 불일치(1건). [측정]
- 불일치 예시: 배우자 있음·상속재산 20억(2,000,000,000원) → 그쪽 232,800,000원 vs 우리 128,871,429원. [측정: s09]
- 원인: 우리는 배우자 상속공제를 "순상속재산 × 1.5/(1.5+자녀수)"(자녀 기본 2명이면 42.86%)와 5억 중 큰 값, 상한 30억으로 잡는다(src/App.jsx:2696, CalcInherit 안 spouseDed 계산). 그쪽은 같은 입력에서 배우자 공제를 5억으로만 적용했다. [측정: 두 화면 / 원인 해석은 코드 읽기]
- s01·s02는 법정상속분(약 4.3억·4.7억)이 5억보다 작아 우연히 일치한다. 그쪽이 실제 배우자 상속분을 입력받지 않아 생기는 차이일 수 있다. [추측]
- 우리 코드는 읽기만 했고 수정하지 않았다.
