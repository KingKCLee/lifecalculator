# 단위가격
- 그쪽 주소: https://부동산계산기.com/단위가격  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /평당가격계산기  · 판정: 불일치

## 1. 입력 항목
- 가격(#price, 만원), 면적(#area), 면적 단위 버튼 ㎡ / 평(hidden #unit = m2 | pyung). [측정: s01, s02 요청 unit=m2|pyung, notes/단위가격.md]
- 우리: 총액(만원), 면적 단위 토글(㎡ / 평), 면적. [측정: ours 표본 화면]

## 2. 계산식 정리
서버 계산이라 식은 보이지 않는다 [추측: 입출력으로 추정한 식].
- ㎡ 면적 = 평 면적 x 3.305785, 평 면적 = ㎡ 면적 / 3.305785 (소수 3자리 표시). s09 에서 ㎡당 1,700,000,000 x 3.305785 = 5,619,834,500 이 평당 가격과 정확히 같아 상수가 3.305785 인 것으로 보인다 [측정: s09 응답; 추측: 상수].
- ㎡당 가격 = 가격(원) / ㎡ 면적, 평당 가격 = ㎡당 가격 x 3.305785. 라벨은 "원 / 평(3.3㎡)" [측정: s01 응답 비고].
- 면적 0 이면 "면적을 입력해 주세요!" 오류(success:false) [측정: s04]. 음수 가격은 음수로 계산 [측정: s13].
- 우리: 평당 가격 = 총액 / (㎡ x 121/400), 상수는 400/121 [측정: notes/단위가격.md 에 인용된 CalcUnitPrice.jsx 5행, ours s06 33,057,851].

## 3. 상수·구간표
- 1평 = 3.305785㎡ (그쪽 추정) / 400/121㎡ = 3.30578512...㎡ (우리). 법령에 평 환산계수 조문은 못 찾음 [측정: law/단위가격.json 근거].

## 6. 판정과 불일치 예시
- 판정: 불일치 (비교 14건 중 6건 일치, 8건 불일치). 7건은 평 상수 차이에서 나오는 1~964원 크기의 반올림 차이이고, 1건(s13)은 음수 가격 입력 처리 차이다.
- 불일치 예시(반올림 차이): 가격 8억 5천만원, 면적 0.5㎡ -> 그쪽 평당 5,619,834,500원 vs 우리 5,619,834,711원. 원인: 그쪽 3.305785(7자리) vs 우리 400/121 [측정: s09, 계산].
- 불일치 예시(기준차이): 가격 -8억 5천만원, 84.9㎡ -> 그쪽 평당 -33,096,787원 vs 우리 결과 없음(음수 거부).

## 7. 못 찾음·미확인
- 그쪽 서버의 반올림 규칙(㎡당 가격이 원 단위 반올림인지 버림인지)은 못 찾음. 표본값은 반올림과 일치한다 [측정: s01 10,011,778.56 -> 10,011,779].
- 법령상 평 환산계수는 못 찾음. 어느 쪽 상수가 맞는지는 법령으로 가리지 못한다 [측정: law/단위가격.json].
