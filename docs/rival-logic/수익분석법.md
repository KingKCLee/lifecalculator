# 수익분석법

## 1. 입력 항목
- 연간 매출액·매출원가·기타 영업경비·보증금: 만원 단위. 임차인 이윤율·보증금 전환율: % (기본 10, 5). [측정: specs/rival/수익분석법.json 표본 s01 요청값]
- 요청에는 recommendCalc=appraisalProfitAnalysis 가 함께 실린다. [측정: s01 요청]
- 우리 쪽 입력: 일반기업 경영 연 순수익, 대상 부동산 귀속 비율(%), 연 필요제경비(만원). 매출·원가·이윤율·보증금 입력은 없다. [측정: ours-capture/runs/수익분석법/s02 화면 텍스트]

## 2. 계산식 정리
서버 계산이라 코드는 보이지 않고, 응답 행의 비고 문구에서 아래 식이 읽힌다 [추측: 입출력으로 추정한 식].
- 매출총이익 = 매출 - 매출원가 [측정: s01 비고]
- 임료 차감 전 영업이익 = 매출총이익 - 기타 영업경비 [측정: s01 비고]
- 임차인 적정이윤 = 매출 x 이윤율 (영업이익이 아니라 매출 기준) [측정: s01 비고 "연간 매출액 x 10%" 와 값 1억, s03 값 2억]
- 부담가능 연 임료 = 영업이익 - 적정이윤 [측정: s01]
- 보증금 연 환산액 = 보증금 x 전환율, 연 임료 = 부담가능 연 임료 - 환산액, 월 임료 = 연 임료 / 12 [측정: s08 응답: 보증금 1억, 5% 이면 환산액 500만원, 연 임료 1.95억]
- 입력 검증: 매출 0 거부(s04), 원가+경비가 매출 이상이면 거부(s05, s11 - 합계가 매출과 같을 때도 거부), 이윤율 100 이상 거부(s07) [측정: 응답 msg].

## 3. 상수·구간표
- 이윤율 허용범위 0 이상 100 미만 [측정: s07 msg]. 기본 이윤율 10%, 기본 전환율 5% [측정: s01].
- 구간표·세율표 없음. 전환율 0%이면 환산액 0 [측정: s09].

## 6. 판정과 불일치 예시
- 비교한 3표본이 원 단위까지 일치하므로 판정은 일치. 단 이 일치는 이윤율 0%·보증금 0 범위 안에서만 성립한다 (R10). [측정: 위 표]

## 7. 못 찾음·미확인
- s04, s05, s07, s11 은 그쪽이 계산을 거부(success=false)해서 비교에서 뺐다. [측정: 응답 msg]
- s01, s03, s08, s09, s10 은 우리에 이윤율·보증금 입력이 없어 비교 불가(구조 차이). [측정]
- 우리 계산식 자체(순수익 x 귀속비율 + 필요제경비)의 근거는 감정평가에 관한 규칙 조문과의 대조를 이번 범위에서 하지 않았다. 그쪽 화면 근거는 "감정평가에 관한 규칙" 계열 수익분석법 설명이다. [측정: 응답 basis 문구]
