## 1. 입력 항목
- 연소득(만원), 대출 행 반복(추가 버튼): 종류 11종(주담대 등), 상환방식 4종(만기일시/원금균등/원리금균등/체증식), 금리(%), 금액 3칸(총액·잔액·만기상환액, 만원), 기간 3칸(총·잔여·거치, 개월). 장래소득 사용(나이), 기준일자(8자리) 선택. DSR 과 신DTI 는 같은 폼의 탭(숨은 값 dcd 가 dsr/newdti)이다. [측정: notes/DSR.md, notes/신DTI.md 의 html 957~1030행]
- 금액·기간 칸은 일반 input 이 아니라 편집 가능한 span 이다. [측정: notes/DSR.md]
- 우리 입력: 연소득, 신규 대출금액, 신규 금리, 대출 유형(고정/혼합 +0.75p/변동 +1.5p), 대출 기간(5~40년), 연령대, 기존 대출 월 상환액 합계. [측정: ours-capture s01 화면 텍스트, App.jsx:2757 CalcDSR]

## 2. 계산식 정리
- 그쪽 서버 DSR 식은 응답을 한 건도 얻지 못해 확인하지 못했다. [측정: rival-capture/runs/DSR/s01~s13 모두 status ERR]
- 우리 식(코드 읽기): 연 원리금 = 원리금균등 월 상환액(스트레스 가산 금리, 연령대 상한 만기 적용) x 12 + 기존 월 상환액 x 12, DSR = 연 원리금 / 연소득 x 100. 은행 40%·비은행 50% 기준 최대 대출액도 표시. [측정: ours-capture s01 화면 / App.jsx:2757]

## 3. 상수·구간표

- 우리: 은행 40%, 비은행 50% 기준, 스트레스 가산 고정 0 / 혼합 0.75p / 변동 1.5p, 연령대별 최대 만기 (30대 35년 등). [측정: ours-capture s01 화면 "연령별 최대 만기 35년"]
