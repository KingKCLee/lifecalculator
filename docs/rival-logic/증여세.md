## 2. 계산식 정리
서버 계산이므로 입출력으로 추정한 식 [추측].
- 과세가액 = 증여재산가액 (채무·비과세 입력이 없는 표본에서는 동일). [측정: s01]
- 과세표준 = 과세가액 − 관계별 증여재산공제 − 결혼·출산공제(입력액, 최대 1억). [측정: s01~s09, s15]
- 산출세액 = 누진세율(10~50%), 세대를 건너뛰면 산출세액 ×1.3("산출세액계"). [측정: s14]
- 납부액 = 산출세액(계) × 0.97 (3% 신고세액공제). [측정: s02, s14]
