# 경매 배당
- 그쪽 주소: https://부동산계산기.com/경매배당  · 계산 위치: 서버  · 측정일: 2026-10-14 [측정:라이브 부동산계산기.com]
- 우리 대응: /경매배당분석 (고정 7칸 순차배당)  · 판정: 불일치

## 1. 입력 항목
- 낙찰 금액(#bid)·선순위 금액(#senior): 만원, 숫자만 입력. 선순위 칸 안내문구는 "경매비용, 최우선변제금액 등"이라 한 칸에 합쳐 넣는 구조다. [측정: rival-capture/html/경매배당.html:800,813]
- 권리 행(가변): 행마다 물권/채권 토글(right[]=m|c)과 금액(amount[], 만원). 첫 행의 "권리 +" 버튼으로 행을 늘린다(첫 행을 복제). [측정: html 1347~1370행, 표본 s02~s04 요청]
- 우리 쪽: 매각대금, 집행비용, 최우선변제(소액임차), 당해세, 1순위 근저당, 2순위 근저당, 일반채권 7칸 고정(전부 만원). [측정: src/calcs/CalcAuctionDiv.jsx:37~43]

## 2. 계산식 정리
서버 계산이라 식은 보이지 않고, 응답의 비고 열에서 읽히는 식이다 [추측: 입출력으로 추정한 식].
- 배당 가능 금액 = 낙찰 금액 - 선순위 금액. 선순위가 낙찰보다 크면 음수 그대로 표시하고 배당 행이 없다 [측정: s06 응답 -10,000,000].
- 물권: 입력 순서대로 각자 금액을 잔액 한도 안에서 우선 배당(물권1, 물권2 ...). 잔액이 모자라면 남은 만큼만 준다(s02 물권2 95,000,000, s09 100,000,000) [측정: s02, s09, 비고 "물권 잔액 우선 배당"].
- 채권: 물권 배당 후 남은 금액을 채권액 비율로 안분. 비고에 "남은금액 x 내 채권액 / 채권 합계" 형태의 식이 그대로 찍힌다(s03 100,000,000x80,000,000/160,000,000) [측정: s03, s04, s10, s14].
- 채권 합계가 남은 금액보다 작아도 같은 안분식이 적용되어, 채권 1건 3,000만원이 1억원 전액을 받는다(분자=분모라 비율 1) [측정: s11 응답 "100,000,000x30,000,000/30,000,000" = 100,000,000]. 채권액을 넘는 배당이다.
- 안분 반올림은 원 단위: s14 에서 50,000x10,000/70,000 등이 7,143·14,286·28,571 이고 합이 50,000 이다 [측정: s14].
- 우리 식: 매각대금에서 7개 항목을 위에서부터 min(남은 금액, 입력액)씩 차례로 떼고, 남으면 "잉여(소유자 환급)". 일반채권은 합계 1칸 순차배당이라 안분이 없다 [측정: CalcAuctionDiv.jsx:21~34].

## 3. 상수·구간표
- 상수·세율 없음. 순위 구조만 있다. 그쪽: 선순위 -> 물권(입력 순서) -> 채권(안분). 우리: 집행비용 -> 최우선변제 -> 당해세 -> 1순위 -> 2순위 -> 일반채권 [측정: 응답 비고 / CalcAuctionDiv.jsx:28~33].
- 물권 3건 이상, 채권 개별 안분액의 우리 쪽 대응 칸은 없다.

## 6. 판정과 불일치 예시
- 판정: 불일치 (비교 13건 중 12건 일치, 1건 불일치). 일치는 "각 권리의 수령액"만 본 결과이고, 그쪽의 배당 가능 금액 행·채권 개별 안분액은 우리 화면에 없어 대조하지 못했다.
- 불일치 예시: 낙찰 1억원, 채권 1건 3,000만원 -> 그쪽 채권1 배당 100,000,000원 vs 우리 일반채권 30,000,000원(잉여 70,000,000원). 원인: 그쪽 안분식이 채권 합계가 남은 금액보다 작아도 비율을 1로 놓아 남은 금액 전부를 채권에 준다 [측정: s11 비고]. 우리는 min(남은 금액, 채권액)이다 [측정: CalcAuctionDiv.jsx:24]. 민사집행법 제145조는 우선순위대로 배당하되 모든 채권자를 만족하게 할 수 없을 때 순위에 따른다고 정하므로 채권액 초과 배당은 근거가 없어 보인다 [측정: law.go.kr 원문, law/경매배당.json].
- 구조 차이(기준차이): 그쪽 물권/채권 가변 행 vs 우리 고정 7칸, 최우선변제·당해세 칸 유무, 선순위 음수 표시(s06) [측정: 문서 1·5번].

## 7. 못 찾음·미확인
- s13 은 그쪽 서버가 HTTP 500 을 돌려줘 비교에서 뺐다 [측정: s13 calls[0].status].
- 그쪽 물권 간 우선순위가 입력 순서인지 금액 순서인지 못 찾음 (표본은 입력 순서만 시험).
- 채권 안분 반올림 방식은 s14 한 건뿐이라 확정하지 못함(7,143+14,286+28,571=50,000 만 관찰).
- 그쪽 채권액 초과 배당이 채권 합계<남은금액인 다른 입력(채권 2건 이상)에서도 나오는지는 시험하지 않았다 [측정: s11 한 건].
